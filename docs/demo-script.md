# SpeakPal 演示脚本（5 分钟录屏 + 现场答辩兜底）

> 用途：录屏一遍过、现场答辩照着走。比 [manual-walkthrough.md](manual-walkthrough.md) 更贴「给评委看」的场景：
> 每一步写清点哪里、说什么、镜头停在哪，外加三条兜底（无 key / 浏览器不支持语音 / 模型不可用）。
> 文案按 `rc22` 之后的界面核对（欢迎页已删、服务端不再兜底 key、学习四板块、暖色练习室）；录屏前以当时最新 tag 为准，别照旧 tag 念。

## 0. 开机前 60 秒
1. `git status` 必须是空的；`git describe --tags` 显示当前演示点（如 `demo-rc25`）。**工作区不干净就别录**——看到的就不是那个 tag。
2. 备份一次库：把 `backend/speakpal.db` 复制到 `.tmp/demo-db-backup.db`（录崩了能一键换回，别在录屏时现做）。
3. 双击 `start-all.bat`，等两个窗口：`SpeakPal BACKEND` 出现 `Uvicorn running on http://127.0.0.1:8000`，前端出现 `Local: http://127.0.0.1:5173`。
4. 浏览器只开一个标签页：Chrome，窗口 1280×720，地址 `http://127.0.0.1:5173`。**关掉开发者工具、关掉书签栏**。
5. **确认是「未登录」状态**：现在没有欢迎页，未登录打开 5173 直接是登录/注册页；本地还留着 token 的话会进首页，0:00 那段「停在登录页」就扑空。
   开录前点「退出」或清掉 `localStorage` 的 token，或直接用隐身窗口 / 新建 Chrome 配置（顺带解决 favicon 缓存）。

6. **先授权一次麦克风、先演练一次填 key**：第一次点麦克风会弹权限框，第一次开练习可能弹密钥面板——这两样都不能进画面。
7. **让历史曲线有数据**：`demo01` 是新账号，只有一个点连线是空的。录前用 demo01 预跑两次（一次录音、一次打字/混合），
   曲线才有两个以上的点、才有空心点可指。来不及就跑一次，4:15 那段改成讲报告页「按推荐再练一次」。
8. 库状态：现在演示点是**空库**（账号也清掉了，7 张表全 0 行），所以先注册 `demo01` 再预跑；顺序必须是**先注册+预跑 → 再录**，别在录屏中途清数据又重练。
9. **浏览器本地残留要单独清**：`localStorage` 里的模型 key / 难度 / 词库范围不随数据库清空，属于这台机器的浏览器数据。要「从头演示」就在 Chrome 里清一次站点数据（或点「退出」+ 设置页「删除本浏览器密钥」），再 `Ctrl+F5`。

## 1. 分镜表（总长 5:00）

| 时间 | 画面 / 操作 | 镜头与停留 | 旁白（照读即可） |
|---|---|---|---|
| 0:00–0:20 | 停在**登录/注册页**（未登录时首屏就是它，欢迎页已删除） | 停 3 秒，光标不动 | 「SpeakPal，一个能给出**可解释分数**的 AI 英语口语陪练。注册只要账号密码，密钥之后在设置里填。」 |
| 0:20–0:40 | 注册：账号 `demo01`、密码 `demo1234`、昵称「小演」→ 提交 | 输入时不要快进 | 「注册不要求密钥，开始练习时才需要。」 |
| 0:40–0:55 | 注册完直接进**首页** | 首页场景卡停 2 秒 | 「第一次进来，先看一眼场景。」 |
| 0:50–1:30 | 首页 →「设置」→ 密钥区填 key → 点「测试连接」 | 成功后停 4 秒，让绿字读得清 | 「模型密钥只存在**这台浏览器**里，服务端不落库、不打日志。测试连接是让后端真的发一次最小请求。」（用**演示专用 key**，录完就吊销；粘贴输入、别镜头怼着键盘，页面也只回显后四位） |
| 1:30–1:45 | 回首页，选「咖啡店点单」，难度「中等」→ 点场景 | 选中态停 2 秒 | 「六个场景，都是真实任务：点单、值机、面试、雅思 Part 1。」 |
| 1:45–2:25 | 练习页：点麦克风 → 说 `I'd like a large latte, please.` → 识别结果进输入条 → 按 Enter | 说话时镜头不动；识别出字后停 3 秒 | 「语音识别结果**先进输入条**，认错了可以改，按 Enter 才发送。这一步是刻意的：不让错误的转写直接进评分。」 |
| 2:25–2:55 | 点「手动输入」，打 `I want coffee and a cake, thank you.` → Enter | 停在「录音 / 打字」气泡标记上 2 秒 | 「也可以打字。每轮都记了作答方式，气泡上标着『录音』或『打字』——因为打字没有语音证据。」 |
| 2:55–3:15 | 再录一句短的回答（让流利度有数据）→ 点「结束并出报告」→ 确认框点「确认生成」 | 确认框停 2 秒 | 「结束时才评分，中途不打断你说话。」 |
| 3:15–4:15 | 报告页：综合得分 + 档位 → 四/五个维度 → 「最该改的 N 句」→ 在「逐句纠错」里点一句的「重说这句」→ 跟读一遍看相似度 → 展开「评分依据（可复现）」 | 每一块停 4–5 秒；跟读成功后停 3 秒 | 「综合分旁边是档位，比如『B1 · 雅思 5.5』。下面这套扣分是**可复现**的：点开能看到模型原分、规则分、最终分，以及哪一维被压了、压了多少。跟读相似度 ≥ 85% 算通过——练完立刻改，这是口语最关键的一环。」 |
| 4:15–4:45 | 历史页：点「成长曲线（可比 band）」看点位，指出空心点 | 曲线停 4 秒 | 「历史曲线画的是**跨模式可比**的 band，只用两种作答都会评的两个维度，所以打字和录音能放进同一条线；打字用空心点。」<br>**只有一次练习时**（曲线只有一个点、连不出线）这句话别念，改讲报告页的「按推荐再练一次」或历史里「进行中 / 未出分」的分支——单点不是 bug，是数据少。 |
| 4:45–5:00 | 回设置 →「我的数据」输「删除」→ 点确认 → 看到「已删除 N 次练习、M 份报告」；切到「个人资料」 | 成功绿字停 3 秒 | 「数据随时能自己清干净，账号还在。分数不是黑箱，数据也不是。」 |

结束语（可选 5 秒）：「发音我们没有声学测评，报告里写的是『文本推断』，这条我们标清楚了。」

**跟读没到 85% 的接话**（别假装通过，把未通过演成闭环更好）：「这次 62%，没到 85%——它会给一句具体提示（词序 / 少读了哪个词），我再来一次。」重读一遍即可，通过与否都照常往下走。

> 设置页那句「没有密钥也可以先跳过」**已经没有了**：服务端不再提供兜底 key，未填 key 时那里只会提示「不填就开不了练习」。旁白别照旧句念。

## 2. 三条兜底（必读，出问题照着说）

### A. 没有自己的 key（评委试玩最常见）

- **触发**：本浏览器没填 key，点场景。
- **屏幕会看到**：场景列表上方展开页内面板「**先接入一个模型密钥**」，两个按钮「去设置填密钥 / 取消」；
没有别的路：面板只有「去设置填密钥 / 取消」，**不存在「用服务端密钥继续」**（服务端已无 key 可借）。
- **怎么说**：「演示前我会先在设置里填自己的 key。没填的话这里只有去设置一条路——这是有意的，不让人进一场注定出示例报告的对话。」
- **不要做**：不要说「不填也能跑」，也不要临时去改代码放宽门禁——后端对没有 key 的开练请求是 `409`，改前端也绕不过去。

### B. 浏览器不支持语音识别（Firefox / 老版 Safari / 麦克风被拒）

- **触发**：点麦克风。
- **屏幕会看到**：`当前浏览器不支持语音识别，请用 Chrome，或点「手动输入」。`
  （权限被拒是另一句：`麦克风权限被拒绝了…`；没出声是 `这次没听到声音…`——三句都是中文，不会裸露 `not-allowed`。）
- **怎么说**：「语音是增强项。这个浏览器不给语音，我改打字——打字报告走 3 个维度，**不给发音和流利度打分**，因为那两维没有证据，我们不编。」
- **动作**：点「手动输入」继续走，后半段完全一样，只是报告里维度少两个、`answer_mode=typed`。

### C. 模型超时 / 网络断了

- **触发**：`finish` 时模型不可用。
- **屏幕会看到**：报告页顶部琥珀条「**示例报告（本次不计分）：…**」（不是红色——这不是用户做错），分数和档位留空，逐句纠错只列用户真实说过的句子；历史里那条显示「未出分」。
- **怎么说**：「模型这一刻不可用，系统**不编分数**。这份是示例报告，本次不计分，历史里也标着未出分。我们宁愿显示没有，也不给假分——这是评分产品最不能踩的线。」
- **补充**：如果观众问「那怎么证明它能算」，回设置页重连一次或下一轮再练；接口层是 `mock_reason=unavailable`，落库可查。

### C2. 用户自己的 key 被模型服务拒绝（错 key / 欠费）

- **触发**：发送或结束时，请求头里的 key 被 401/403。
- **屏幕会看到**：对话区切到页内面板「**你的密钥被模型服务拒绝了**」，给「去设置填密钥 / 返回练习」。
- **怎么说**：「这是 key 的问题，不是网络问题，系统分得清：它会明确告诉你换 key，这句话**没有计入记录**，换好 key 可以接着练。这跟『模型不可用』是两条路，提示不一样。」

## 3. 录屏纪律

- 不打开开发者工具、不点「管理台」、不展示 `.env`。0:50 要填 key，所以用**演示专用 key**（录完吊销），粘贴输入、不在画面里放大输入框；页面本身也只回显后四位。
- 只在需要时刷新；刷新会回到同一场练习（`/practice/:id`），可以顺手当成一个加分点讲。
- 演示期间**不要有人改文件**：`git status` 一非空，看到的就不再是当前 tag。
- 录完把 `demo01` 账号注销（或清数据），演示库回到「1 账号 0 会话」，下一场不用清理。
- 预跑留下的两次练习**别删**：历史曲线要靠它们，删了 4:15 那段就只剩一个点。

## 4. 答辩三句话（评委一定会问）

1. **分数怎么算**：模型按雅思描述语给每维 band（0.5 步长）→ `S = 10B + 10` 换 0–100（全项目唯一换算入口 `evaluation/bands.py`）→ 与可测规则分融合（流利度 0.5、语法 0.35、任务 0.6，发音只用模型）→ **只压不抬**，压分原因和原分全部落库可复算 → 综合分按作答模式加权。
2. **band 怎么锚**：CEFR/雅思官方对照 B1=4.0–5.0、B2=5.5–6.5、C1=7.0–8.0，取整 `floor(B×2+0.5)/2`，<40 分不给档；`evaluation/validate.py` 用 ICC / kappa / Bland-Altman 与人评对齐——**合成数据只证明通路，不是真实结论**，这句要主动说。
3. **为什么打字和录音分开**：打字没有语音证据，硬给发音和流利度就是凭感觉。每轮记 `input_mode`，纯打字 3 维、录音 4 维、混合 5 维；跨模式比较只看 `comparable_band`（共享的两个维度）。

## 5. 出事怎么办

| 现象 | 先看 | 处理 |
|---|---|---|
| 页面白屏 | 前端窗口有没有报错 | 关掉重开 `start-all.bat`；确认 `git status` 为空 |
| 接口 404/502 一片 | 8000 是不是旧进程 | 停掉旧后端再 `start-all.bat`（旧进程不会自动换代码） |
| 端口被占 | 8000 / 5173 | 关掉占用进程；`start-all.bat` 第二次通常能自己接上 |
| 库被清空/弄乱 | — | 用第 0 步备份的 `.tmp/demo-db-backup.db` 覆盖 `backend/speakpal.db`，重启后端 |
| 麦克风没反应 | 地址栏权限图标 | 允许麦克风；不行就按兜底 B 打字，不要现场装插件 |
