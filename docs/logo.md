# SpeakPal 品牌标识规范 v1

> 负责人：logo设计师。落地状态：矢量在 `frontend/public/`，**图形只有这一份真源**——`frontend/src/components/BrandLogo.vue` 只按尺寸/深浅挑文件，不复制几何，所以改 SVG 就是全站生效；
> 色值只取 [docs/ui-visual.md](ui-visual.md) 的色板，末节有实测对比度与未验证项。

## 1 释义

一个**气泡**（你在说）、三根**递增高声波柱**（口语 → 进步 → 评分）、一颗**星标**（陪练在回应）。
不画人、不画麦克风、不用渐变：品牌要「可信、鼓励、专注」，不靠装饰。

## 2 几何（64×64 网格）

| 部件 | 参数 |
| --- | --- |
| 气泡 | `rect x=2 y=14 w=40 h=30 rx=10` |
| 气泡尾 | 从 `(12,43)` 三次贝塞尔到尖端 `(7.4,54.2)`，回到 `(28,43.5)`；尾长约为气泡高 1/3，圆尖不用直角 |
| 声波柱 | 宽 5、圆角 2.5，x = 10 / 19.5 / 29，高 8 / 14 / 20，垂直居中于 y=29；**柱间空隙固定 4.5 单位** |
| 星标 | 圆 `(53,11) r=10`，白色四尖星 r=6.2，与气泡四角不相切 |
| 无底版 | 整组 `translate(10,-3.7)` 居中于 64 画布，四周留白相等（左右各 12、上下各 10.3） |
| 完整标 | 整组 `translate(0,2.8)`：墨迹从 1..57.4 变成 3.8..60.2，和文字横排时不会偏上 |

## 3 颜色

| 角色 | 值 | 用在哪 |
| --- | --- | --- |
| 主色 | `#14806F`（`brand-600`） | 气泡主体、无底版；深底版里作挖空柱色 |
| 反白 | `#FFFFFF` | 气泡内三根柱；深底版的气泡主体 |
| 星标 | `#38BDF8` | 只出现在星标圆底，白色星；全站唯一冷色点缀，不加第四色 |

实测对比度（WCAG 2.1，相对亮度公式）：

| 前景 / 背景 | 比值 | 结论 |
| --- | --- | --- |
| `#14806F` / 白 | **4.83:1** | 图形对象需 3:1，达标；白底上做主色文字也过 4.5 |
| 白 / `#14806F` | **4.83:1** | 品牌青按钮上的白字达标 |
| `#14806F` / `#F5F8F8`（页面底色） | **4.52:1** | 达标 |
| 白柱 / 青气泡 | **4.83:1** | 柱的轮廓清晰 |
| `#38BDF8` / 白 | 2.14:1 | **不达标**，所以星标只做装饰，不承载信息、不当唯一识别符 |
| `#38BDF8` / `#14806F` | 2.26:1 | 同上 |

## 4 尺寸与实现档位

| 场景 | 用哪版 | 实测 |
| --- | --- | --- |
| 登录页标记 46px | `logo.svg`（带星） | 星标圆 7.2px，清晰 |
| 页头 30px | `logo-mark.svg` / `<BrandLogo :size="30" />` | 柱宽 2.34px、间隙 2.11px |
| 24px 最小推荐 | 同上 | 柱宽 1.88px、**间隙 1.69px（≥1px，达标）** |
| 16px | `favicon.svg`（有底色版） | 柱宽 1.75px、间隙 1.25px |
| 收藏夹 / PPT / PWA | `logo-app.svg`（512 有底色） | 柱宽 30px、间隙 30px |

`<BrandLogo>` 的规则：星标在 `size < 32` 时自动隐藏（30px 页头只剩气泡+柱，不会糊成白点），`badge=false` 可强制关闭。

## 5 文件清单

| 文件 | 版本 | 用途 |
| --- | --- | --- |
| `frontend/public/logo.svg` | 完整标（带星，透明底） | ≥32px：登录页、README、答辩封面 |
| `frontend/public/logo-mark.svg` | 无底无星 | 页头、卡片、任意浅色底，16–40px |
| `frontend/public/logo-mark-inverse.svg` | 白气泡 + 青柱 | 深色底页头 |
| `frontend/public/logo-inverse.svg` | 完整标反白 | 深色底大图 |
| `frontend/public/favicon.svg` | 青底方标（16px 优化） | 浏览器标签 |
| `frontend/public/logo-app.svg` | 512 应用图标 | 收藏夹、PWA、PPT、头像 |

页面里**统一走组件**，不要直接 `<img src="/logo.svg">`：组件按 `size` / `tone` 自动挑上表里的文件（≥32 带星、<32 换居中简化版、深色底换反白版），并处理 `alt`。

组件档位表（`frontend/src/components/BrandLogo.vue`）：

| 条件 | 实际加载 |
| --- | --- |
| `size ≥ 32`，浅底 | `/logo.svg` |
| `size ≥ 32`，`tone="inverse"` | `/logo-inverse.svg` |
| `size < 32`，浅底 | `/logo-mark.svg` |
| `size < 32`，`tone="inverse"` | `/logo-mark-inverse.svg` |

## 6 用法

```vue
<!-- 页头：图标 + 文字 -->
<BrandLogo :size="30" wordmark />

<!-- 登录页：只要图标，星标自动显示（≥32） -->
<BrandLogo :size="46" />

<!-- 深色底 -->
<BrandLogo :size="30" tone="inverse" />

<!-- 欢迎页 / 答辩封面：图标在上、字标居中 -->
<BrandLogo :size="64" wordmark layout="stacked" />
```

### 6.1 欢迎页首屏（品牌展示位）

| 元素 | 规格 |
| --- | --- |
| 标记 | 64px（≥32 自动带星标，用 `/logo.svg`） |
| 字标 | 40px（= 64 × 0.62），`Speak` = `ink`、`Pal` = `brand-600` |
| 图标与字标间距 | 12px（`layout="stacked"` 内置） |
| 定位句 | 字标下 8px，14px `ink-soft`：「场景化 AI 英语口语陪练」 |
| 底色 | `canvas`；深色首屏用 `tone="inverse"` |
| 频次 | 首屏只出现一次标识，页脚不要重复 |
| 光晕 | 允许，但不透明度 ≤ 60%，不能压住字标笔画 |

欢迎页、新手引导里**不要手写「SpeakPal」文字**：字号、字距、`Pal` 的配色都写在组件里，手写一定跑偏。

字标（文字部分不画矢量，避免字体依赖）：**`Speak` 用 `ink`，`Pal` 用 `brand-600`**，同一字重 700、字距 `-0.02em`；
字号 = 标记高度 × 0.62（30px 标记 → 19px 字），图标与文字间距 10px。深色底 `Pal` 用 `brand-300`。

## 7 禁止

- 不改色、不加渐变、描边、投影、外发光；不在品牌青底上叠青标（换反白版）。
- 不拉伸、不加宽气泡、不把尾巴改成直角；柱不加到 4 根以上、不改成等高。
- 不旋转、不把星标挪进气泡内、不给星标加文字。
- 不把「气泡+柱」单独拆出来当按钮图标（场景卡用线性 SVG 图标，见 `components/SceneIcon.vue`）。
- 不在 16px 以下用无底色版；不把有底色版当页头图标（两者用途正好相反：页头无底、收藏夹有底）。

## 8 落地位置

`index.html` favicon + `theme-color`、登录页、首页页头、历史页、报告页页头、欢迎页首屏（§6.1）；答辩 PPT 封面用 `logo-app.svg`。

## 9 校验方式与未验证项

已做：几何数值自检（间隙/尺寸换算见 §4）、WCAG 对比度按公式实算（§3）、`BrandLogo.vue` 用 `@vue/compiler-sfc` 进程内编译通过（模板 + 绑定无错）。
未做：**浏览器截图**。本机沙箱起不了 Chrome 无头（命名管道被拒）也起不了 esbuild 子进程，所以我用 .NET 按同一组坐标近似重绘做了目视检查，不是浏览器渲染证据。
SVG 本身只含纯色块与路径、无字体与滤镜依赖，理论上任何浏览器渲染一致；真机走查时请顺手确认 16px 标签页图标和页头 30px 标记的观感。
