| 项 | 值 |
| --- | --- |
| 适用版本 | `58c8e62` 之后的前端工作区（ui设计师 正在改 `/practice/:id` 刷新恢复，提交后需再走 A 项） |

## 0. 准备

1. 临时库启动：设 `DATABASE_URL=sqlite:///<仓库外临时目录>/walk.db` 后 `start-backend.bat`；前端 `start-frontend.bat` 走 5173 代理 8000。走完删临时库。
2. 浏览器 Chrome（`SpeechRecognition` 只有 Chrome/Edge 可用），两档宽度 **360×640** 和 **1280×800**。
3. 真麦克风；另备一次「麦克风=阻止」的站点设置操作（异常 E）。
4. 账号 A 走主流程、B 验数据隔离。
5. 截图 `shots/S01-*.png` … `S12-*.png`，必须含页面标题 + 关键文案，不截开发者工具。
6. 记录表在 §5，边走边填。

## 1. 主流程（8 步）

### 步骤 1 · 注册 A

- 动作：打开 `http://127.0.0.1:5173` → `没有账号？去注册` → `walkA` / `1234` → 注册。
- 预期文案：标题 `SpeakPal`、副标题 `场景化 AI 英语口语陪练`；字段标签 `账号` / `密码` / `昵称`（placeholder `昵称（可选）`）；按钮 `登录` ↔ `注册`；底部 `没有账号？去注册` ↔ `已有账号？去登录`；空提交红字 `请填写账号和密码`。
- 断言：`localStorage` 出现 `sp_token`、`sp_user`；注册后首跳——服务端有兜底 key 进首页，没有则进设置引导页。
- 截图位 S01：注册态 + 空提交红字。

### 步骤 2 · 个人资料与模型密钥

- 2a 个人资料：改昵称为 `走查A` → `保存昵称` → 绿字 `昵称已更新。`；顶栏「你好，走查A」即时变化；昵称清空 → `昵称不能为空`。
- 2b 改密码：`当前密码` / `新密码` / `再输一次` 三格 → `修改密码`。空当前密码 → `请先填当前密码`；新密码不足 4 位 → `新密码要 4–64 位`；两次不一致 → `两次输入的新密码不一致`；成功 → `密码已更新，下次登录用新密码。`，旁边小字 `改完密码，其他设备上的登录不会掉线。`
- 2c 模型密钥：填可用 key → `保存` → `已保存到本浏览器。`；状态行 `当前：已配置（****后四位）· 服务端已配置兜底密钥`。
- 断言：`localStorage["sp_llm"]` 有 `api_key`；后端库任何表都不出现该 key；改密后**旧 token 仍可用**（这是设计，别当 bug 报）。
- 截图位 S02：设置页四块（个人资料 / 模型密钥 / 我的数据 / 注销账号）；S03：引导页黄条（若首跳是引导页）。

### 步骤 3 · 测试连接

- 动作一：`测试连接` → `测试中…` → `连通 · 模型 deepseek-chat · 123 ms`。
- 动作二：key 末位改掉 → 保存 → `测试连接` → `密钥无效或被拒绝：<服务端原始错误>`。
- 断言：`POST /api/config/llm/test`；失败时 `ok=false`、`error_kind=invalid_key`；页面与响应都不回显完整 key。
- 截图位 S04：失败提示。

### 步骤 4 · 开练

- 4a 无 key 拦截（用户明确要求）：`删除本浏览器密钥` → 回首页点任一场景 → 必须被拦：红字 `还没接入模型：请到「设置」里填一个 API Key，或用服务端配置的兜底密钥。` 并跳 `设置?onboarding=1`；此时 `sessions` 应 0 行。
- 4b 开练：填回 key → 选 `咖啡店点单`、难度 `中等`。
- 预期文案：首页 `你好，walkA`、`选一个场景，开始说英语`、`和 AI 角色多轮对话，结束后拿到评分和逐句纠错。`；三张卡 `求职面试` / `咖啡店点单` / `雅思 Part 1`；练习页头部品牌标 + 难度胶囊 `难度 中等`；开场白 `Hi there! What can I get for you today?`。
- 断言：`POST /api/sessions` 200；`GET /api/sessions/{id}` 返回 `status=active`、turns 1 条 ai；开场白自动朗读。
- 截图位 S05 首页三卡（1280）；S06 练习页初始态（360）。

### 步骤 5 · 说两句（语音 + 页面内手动输入）

- 语音：点麦克风 → 按钮下出现 `录音中 0:0x` 文字计时（不能只靠变色）；说 `I'd like a large iced latte, please.` → 自动结束发送；发送中显示 `正在回复…` 与三点加载气泡。
- 手动输入（重点，用户要求不许弹浏览器窗）：点 `手动输入` → 底部就地展开输入条，placeholder `用英文写下你的回答，Enter 发送，Shift+Enter 换行`，`发送` / `取消` 两个按钮；自动聚焦；`Enter` 发送、`Shift+Enter` 换行、`Esc` 关闭且焦点回到 `手动输入`；全程无浏览器原生弹窗。
- 断言：两轮后 turns 5 条（ai/user/ai/user/ai）；用户原句逐字落库；后端拒收（空/超长/502）时刚乐观插入的那句会被**撤回**，不留在界面上；502 时提示 `你的密钥被模型服务拒绝了，去设置里换一个再试；这句话没有计入记录。`
- 截图位 S07 对话中（两条用户气泡 + AI 回复 + 底部三键）；S08 手动输入条展开态；S09 录音中计时。

### 步骤 6 · 结束并出报告

- 动作：`结束并出报告` → 出确认条 `生成报告后这次对话就结束了，确定吗？` → `确认生成` → `生成中…` → 跳 `/report/{id}`。
- 零轮防护：刚开练就点结束 → 红字 `先至少聊一轮，说一句再生成报告。`
- 答满 4 轮后：底部出现 `已经聊了几轮，可以生成报告看评分了。` + `现在生成`。
- 预期文案（真实评分为准）：标题 `复盘报告`；`综合得分` + 大数字；档位 `B1 · 雅思 5.5`；小字 `分数由 AI 估算，仅供参考。`；`四个维度`（副标题 `模型分与可测指标融合`，四维各带 `雅思 x.x`）；`流利度与表达指标`；`评分依据（可复现）`（`模型 x · 规则 x · 最终 x`）；`逐句纠错`（`原句` 红色删除线 + `改写` 绿色 + 中文原因）；底部 AI 点评；`再来一次` / `看历史`。
- 断言：`source=llm`、`total_score` 非空、四维齐全、bands 在 3.0–9.0；`sentence_fixes[].original` 必须逐字来自用户发言。
- 降级分支：key 改坏再练一轮 → finish 仍 200，黄色横幅 `示例报告（本次不计分）：` + 原因；`unavailable` 时**不出现** `去设置`。
- 截图位 S10 报告首屏；S11 逐句纠错区。

### 步骤 7 · 清练习数据（重点）

- 动作：设置页 `清除我的练习数据` → 输入 `删除` → `确认删除`。
- 预期文案：`确认删除你的全部练习记录与报告？输入「删除」两个字再点确认。`；输错 `请先输入「删除」两个字`；成功绿字 `已删除 N 次练习、M 份报告。`。
- 断言：历史页空态 `还没有练习记录。` + `去练一次`；`GET /auth/me` 200（账号还在）；B 的会话仍在；库里该用户 sessions/turns/reports 归零。
- 实测参考：2 次练习 → `deleted_sessions=2, deleted_turns=6, deleted_reports=1`。
- 截图位 S12 删除成功绿字；S13 历史空态。

### 步骤 8 · 注销账号（重点）

- 动作：设置页 `注销我的账号` → 输入 `注销` → `确认注销`。
- 预期文案：`确认注销「walkA」？输入「注销」两个字再点确认。`；输错 `请先输入「注销」两个字`；成功回 `/login`。
- 断言：`localStorage` 的 `sp_token`/`sp_llm` 被清；旧 token 请求 → 401（`detail=用户不存在`）；同名可重新注册。
- 实测参考：错 confirm 400 `注销不可恢复，请输入「注销」确认`；正确 200 `deleted_account=1`。
- 截图位 S14 注销确认区。

## 2. 异常项（记录现状，不阻塞发布）

| 编号 | 场景 | 操作 | 当前行为 | 期望 |
| --- | --- | --- | --- | --- |
| A | 刷新中断 | 对话 2 轮后 F5 | 工作区已在做：路由加 `/practice/:id`，进页先 `GET /api/sessions/{id}` 回填（未提交，待真机验）。历史里未完成会话**仍跳 `/report/{id}`**，进去是红字 `加载报告失败：报告不存在`（后端 404） | 刷新后原地回填；未完成会话落「继续练习」，不能跳到 404 |
| B | 双开标签 | A 已开练，另一标签改 key / 注销 | 两标签内存态独立，B 改的 key 对 A 不生效（要刷新）；A 注销后 B 下一次请求 401 被踢登录 | A 侧提示「密钥已更新，刷新生效」；被踢时说明原因 |
| C | token 过期 | 后端 `JWT_EXPIRE_MINUTES=1` 重启，登录后等 60s+ 再操作 | 工作区已加：401 → 清 token 跳 `/login?expired=1`，登录页显示 `登录状态已过期，重新登录就能接着练（练习记录还在）。`；但登录成功后回 `/` 而不是 `/practice/{id}`，说「接着练」对不上 | 登录后能回到原练习页，或把文案改成「重新登录即可继续」 |
| D | 超长输入 | 手动输入粘贴 6000 字符 | 后端 400 `单轮回答太长了（上限 2000 字符），可以分两句说`；恰好 2000 收、2001 拒；首尾空格先去掉再判长；前端无字数计数 | 输入条 `maxlength=2000` + 计数，超限在本地就拦，别等后端 400 |
| E | 麦克风被拒 | Chrome 站点设置把麦克风设为阻止，点麦克风 | `语音识别出错：not-allowed`（英文错误码直接露出） | `浏览器拒绝了麦克风权限，请允许后重试，或改用「手动输入」` |

补充两条：Firefox 点麦克风应出 `当前浏览器不支持语音识别，请用 Chrome，或点「手动输入」。`；已结束会话再发言应出 `发送失败：会话已结束`。

## 3. 本轮实测（临时库，测完已删，`backend/speakpal.db` 未动）

| 场景 | 结果 |
| --- | --- |
| 6034 字符一次发言 | `400`「单轮回答太长了（上限 2000 字符），可以分两句说」，不落库 |
| 恰好 2000 / 2001 字符 | `200` / `400`；前后各 5 空格 + 2000 字符 → `200`（先 strip 再判长） |
| `""` / `"   "` / 制表换行 / 全角空格 | 均 `400`「这一轮没有听到内容，请再说一遍或手动输入」，`turns` 行数不变 |
| 0 轮直接 finish | `400`「还没有任何回答，先至少聊一轮再生成报告」，`reports` 0 行 |
| 有 1 轮后 finish（模型不可达） | `200`、`source=mock`、`total_score=null`，`sentence_fixes` 2 条且全来自用户原句 |
| 同一会话 finish 两次 | `200`，同一个 `report_id` |
| 未完成会话读报告 | `404`「报告不存在」（History 现在会点进去，页面显示加载失败） |
| 会话详情 `GET /sessions/{id}` | `200`，`status=active`，turns 1 → 5 条，roles `ai/user/ai/user/ai` |
| 改昵称 / 改密 | 200；改密缺当前密码 400、当前密码错 400、旧密码登录 400、新密码 200；**旧 token 仍 200** |
| 清练习数据 | 200，`deleted_sessions=2, deleted_turns=6, deleted_reports=1`；账号仍 200 |
| 注销 | 错 confirm 400、正确 200；旧 token 401「用户不存在」；同名重注册 200 |
