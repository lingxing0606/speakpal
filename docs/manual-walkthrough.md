## 1. 主流程（8 步）

### 步骤 1 · 首次打开 → 登录页 → 注册

- 动作：清掉 `localStorage` 的 `sp_token`/`sp_user`（模拟新访客），打开 `http://127.0.0.1:5173` → **未登录首屏直接是 `/login`**（欢迎页已删，`/welcome` 不再存在）。
- 预期文案：`SpeakPal`、`场景化 AI 英语口语陪练`、`欢迎回来`；字段 `账号` / `密码`；底部 `没有账号？去注册`。
- 动作续：`walkA` / `walkA1234` → 注册 → **没配 key 时直接进 `/settings?onboarding=1`**，页面自动滚到「模型密钥」块（该块在视口内）；填 key 保存后回首页。
- 断言：`localStorage.sp_welcomed` / `sp_intro_seen` 不再产生；直接访问 `/welcome` 不再有页面（兜底回 `/` 或 `/login`）；登录页 `next=/welcome` 这类旧参数会被忽略。
- 旧 token 自愈（全部落登录页，按原因给文案）：乱码/无效凭证 → `/login?reason=token_invalid`；已注销账号的旧 JWT → `/login?reason=user_gone`；改密被踢 → `/login?reason=password_changed`。
- 截图位 S01 登录页（未登录）；S02 注册态。

### 步骤 2 · 设置页：个人资料 / 改密 / 密钥

- 2a 改昵称：`保存昵称` → `昵称已更新。`；顶栏 `你好，走查A` 即时变。
- 2b 改密码（**行为已反转，重点**）：`当前密码` / `新密码` / `再输一次` → `修改密码`。
  - 本机改完**不掉线**，提示 `密码已更新，下次登录用新密码。`，继续能操作（响应里的新 token 已自动存回）。
  - 另一个登录态（第二浏览器/无痕）下一次请求 → 401 `密码已修改，请重新登录`，被踢回登录页，登录页按 `?reason=password_changed` 显示「密码已修改」文案。
  - 页面上**不应再出现**「改完密码，其他设备上的登录不会掉线」这类小字（用户明确要求删）。
  - 空当前密码 `请先填当前密码`；不足 6 位 `新密码要 6–64 位`；两次不一致 `两次输入的新密码不一致`。
  - 断言：旧密码登录 400 `账号或密码错误`；新密码 200；两台设备的旧 token 都 401。
- 2c 模型密钥：填 key → `保存` → `已保存到本浏览器。`；状态行 `当前：已配置（****后四位）`。
- 截图位 S03 设置四块；S04 改密成功；S05 第二浏览器被踢。

### 步骤 3 · 测试连接

- `测试连接` → `测试中…` → `连通 · 模型 deepseek-chat · 123 ms`；坏 key → `密钥无效或被拒绝：…`。
- 断言：`POST /api/config/llm/test`；失败 `error_kind=invalid_key`；页面与响应都不回显完整 key。
- 截图位 S06。

### 步骤 4 · 开练（6 场景，必须自带密钥）

- 4a 密钥门槛（**已定稿**）：服务端不再提供 key。本机没 key 时点场景 → 页内面板只有 `去设置填密钥` 与 `取消`，**没有**「用服务端密钥继续」；此时不应新建会话。
- 4b 去设置填 key → 回首页：`你好，walkA`、`选一个场景，开始说英语`；六张卡 `求职面试` / `咖啡店点单` / `雅思 Part 1` / `酒店入住` / `机场值机` / `餐厅点餐`，图标互不相同（线稿）。
- 4c 选 `酒店入住`、`中等` → 练习页 `难度 中等`；开场白随场景。
- 断言：`GET /api/scenes` 6 条；`POST /api/sessions` 200；地址变成 `/practice/{id}`。
- 截图位 S07 首页六卡（1280）；S08 练习页（360）。

### 步骤 5 · 说两句：录音与打字必须分开（重点）

- 语音：点麦克风 → `录音中 0:0x` → 说完识别结果进输入条（`这是识别到的内容，确认或改一下，按 Enter 发送。`）→ Enter 发送；该轮气泡标 **`录音`**。
- 打字：`手动输入` 写一句发出；或把识别结果改过再发；该轮气泡标 **`打字`**。
- 混合：一轮录音、一轮打字，两轮都要在。
- 断言：`GET /api/sessions/{id}` 的 turns 里，用户轮 `input_mode` 分别为 `voice` / `typed`；改过文字的轮次请求体 `audio=null`；历史列表 `voice_turns/typed_turns` 计数正确。
- 注意：**AI 开场白的 `input_mode` 也是 `voice`**（后端默认值），前端不要给 AI 气泡标「录音」。
- 截图位 S09 语音轮；S10 打字轮；S11 两种气泡同屏。

### 步骤 6 · 结束并出报告：3 / 4 / 5 维（重点）

- 动作：`结束并出报告` → `生成报告后这次对话就结束了，确定吗？` → `确认生成`。
- 纯录音（全程麦克风）：4 维 `发音清晰度` / `流利度` / `语法词汇` / `任务完成度`，各带 `雅思 x.x`。
- 纯打字（全程手动输入）：
  - 只有 **3 维**：`语法词汇` / `任务完成度` / **`文字表达`**，**没有发音、没有流利度**；
  - 顶部横幅必须写 `本次为打字作答，发音 / 流利度未计入综合分。想练发音就点麦克风说几句，再练一次。`
  - 区块标题写实际个数（`3 个维度`），**不能写死「四个维度」**。
- 混合：5 维（多 `文字表达`），顶部 `这次录音和打字都有：发音、流利度只统计录音的句子，「文字表达」只统计打字的句子。`
- 综合分按作答模式加权（工作区实现，待提交）：录音 20/20/30/30；打字 35/35/30；混合 15/15/20/25/25。**不是等权平均**，用维度分值手算一次核对。
- 降级分支：key 坏掉 → finish 仍 200，黄横幅 `示例报告（本次不计分）：`，分数与档位为空。
- 截图位 S12 录音报告；S13 打字报告（含横幅与 3 维）；S14 混合报告。

### 步骤 7 · 清练习数据

- 设置页 `清除我的练习数据` → 输入 `删除` → `确认删除` → `已删除 N 次练习、M 份报告。`；历史空态 `还没有练习记录。` + `去练一次`。
- 断言：账号仍在（`/auth/me` 200）；B 的数据不受影响；该账号下 sessions/turns/reports 归零。
- 截图位 S15。

### 步骤 8 · 注销账号

- `注销我的账号` → 输入 `注销` → `确认注销` → 回 `/login`；旧 token 401 `用户不存在`；同名可重注册。
- 截图位 S16。

## 2.7 两把密钥（对话 + 语音合成）验收口径

> 对话密钥必填（只存本浏览器，服务端不提供）；语音合成密钥可选，**任何失败都必须回落浏览器朗读，宁可声音普通也不能没声音**。

| # | 检查 | 通过标准 |
| --- | --- | --- |
| 1 | 设置页两块 | `对话密钥`（必填说明）与 `语音合成密钥（可选）` 都在；TTS 块含 key / base_url / model / voice，说明写清「不填用浏览器朗读；填了走第三方计费」 |
| 2 | 官方链接 | 每块「怎么拿 key」的链接实际能打开（浏览器访问 200、是供应商官网页面），不是记忆里的死链 |
| 3 | 不填 TTS | 练习页自动朗读与 🔊 都出声；请求不带 `X-TTS-*` |
| 4 | TTS key 错 | `POST /api/tts` → 502 `tts_key_invalid` → 仍回落浏览器朗读，页面给一句不阻塞的提示 |
| 5 | TTS 不可达/超时 | 502 `tts_unavailable` → 回落朗读；对话、报告、跟读都不被卡住 |
| 6 | 无 key 时的 TTS 请求 | 前端直接走浏览器朗读，不出现 409 白屏、不刷 console error |
| 7 | 密钥落点 | 两把 key 只存 localStorage；后端库与日志搜不到；请求头分别 `X-LLM-*` / `X-TTS-*` |
| 8 | 退出与踢线 | 主动退出清本机两把 key；被 401 踢下线不清（沿用现有规则） |
| 9 | 跟读不受影响 | 跟读靠语音识别，TTS 失败时跟读按钮与评分仍可用 |
