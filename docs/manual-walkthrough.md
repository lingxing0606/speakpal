# SpeakPal 真机走查脚本（产品功能体验）

| 项 | 值 |
| --- | --- |
| 适用版本 | `38b002a` 之后的前端工作区（ui设计师 已落 `/practice/:id` 回填、历史分支、设置页重写；均未提交） |
| 执行人 / 频次 | 产品测试；每次可演示版本 1 次，约 25 分钟 |
| 判定口径 | 主流程 8 步**全部通过**才算「可演示」；异常 5 项记录现状与是否阻塞，不当场修 |
| 与后端验收的分工 | 代码测试覆盖接口级验收；本脚本只走**真实浏览器 + 真实麦克风**，看文案、焦点、返回路径、数据落点 |
| 文案来源 | 逐字取自 `frontend/src/views/*.vue` 工作区当前版本；ui设计师 再改文案要同步改这里，否则会误报 |

> 走查必须用临时库（见 §0），否则会往 `backend/speakpal.db` 写新账号，违背「用户数据清零后不保留」。

## 0. 准备

1. 临时库启动：设 `DATABASE_URL=sqlite:///<仓库外临时目录>/walk.db` 后 `start-backend.bat`；前端 `start-frontend.bat` 走 5173 代理 8000。走完删临时库。
2. 浏览器 Chrome（`SpeechRecognition` 只有 Chrome/Edge 可用），两档宽度 **360×640** 和 **1280×800**。
3. 真麦克风；另备一次「麦克风=阻止」的站点设置操作（异常 E）。
4. 账号 A 走主流程、B 验数据隔离。
5. 截图 `shots/S01-*.png` … `S15-*.png`，必须含页面标题 + 关键文案，不截开发者工具。
6. 记录表在 §5，边走边填。

## 1. 主流程（8 步）

### 步骤 1 · 注册 A

- 动作：打开 `http://127.0.0.1:5173` → `没有账号？去注册` → `walkA` / `1234` → 注册。
- 预期文案：标题 `SpeakPal`、副标题 `场景化 AI 英语口语陪练`；字段标签 `账号` / `密码` / `昵称`（placeholder `昵称（可选）`）；按钮 `登录` ↔ `注册`；空提交红字 `请填写账号和密码`。
- 断言：`localStorage` 出现 `sp_token`、`sp_user`；首跳——服务端有兜底 key 进首页，没有则进设置引导页。
- 截图位 S01：注册态 + 空提交红字。

### 步骤 2 · 个人资料与模型密钥

- 2a 改昵称：`保存昵称` → 绿字 `昵称已更新。`；顶栏 `你好，走查A` 即时变化；清空 → `昵称不能为空`。
- 2b 改密码：`当前密码` / `新密码` / `再输一次` → `修改密码`。空当前密码 → `请先填当前密码`；不足 4 位 → `新密码要 4–64 位`；两次不一致 → `两次输入的新密码不一致`；成功 → `密码已更新，下次登录用新密码。`，旁边 `改完密码，其他设备上的登录不会掉线。`
- 2c 模型密钥：填可用 key → `保存` → `已保存到本浏览器。`；状态行 `当前：已配置（****后四位）· 服务端已配置兜底密钥`。
- 断言：`localStorage["sp_llm"]` 有 `api_key`；后端库任何表都不出现该 key；改密后**旧 token 仍可用**（设计如此，别报成 bug）。
- 截图位 S02：设置页四块（个人资料 / 模型密钥 / 我的数据 / 注销账号）；S03：引导页黄条（若首跳是引导页）。

### 步骤 3 · 测试连接

- 动作一：`测试连接` → `测试中…` → `连通 · 模型 deepseek-chat · 123 ms`。
- 动作二：key 末位改掉 → 保存 → `测试连接` → `密钥无效或被拒绝：<服务端原始错误>`。
- 断言：`POST /api/config/llm/test`；失败 `ok=false`、`error_kind=invalid_key`；页面与响应都不回显完整 key。
- 截图位 S04：失败提示。

### 步骤 4 · 开练

- 4a 无 key 拦截（用户明确要求）：`删除本浏览器密钥` → 回首页点场景 → 必须被拦：红字 `还没接入模型：请到「设置」里填一个 API Key，或用服务端配置的兜底密钥。` 并跳 `设置?onboarding=1`；此时 `sessions` 0 行。
- 4b：填回 key → 选 `咖啡店点单`、`中等` → 开练。
- 预期文案：首页 `你好，walkA`、`选一个场景，开始说英语`、`和 AI 角色多轮对话，结束后拿到评分和逐句纠错。`；三张卡 `求职面试` / `咖啡店点单` / `雅思 Part 1`；练习页难度胶囊 `难度 中等`；开场白 `Hi there! What can I get for you today?`。
- 断言：`POST /api/sessions` 200；**地址栏变成 `/practice/{id}`**（刷新靠它回填）；`GET /api/sessions/{id}` 返回 `status=active`、turns 1 条 ai；开场白自动朗读（刷新回填时**不重播**）。
- 截图位 S05 首页三卡（1280）；S06 练习页初始态（360，含 `/practice/1` 地址）。

### 步骤 5 · 说两句（语音确认 + 页面内输入，重点）

- 语音（不再是说完就发）：点麦克风 → 出现 `录音中 0:0x` 文字计时（不能只靠变色）→ 说完后识别结果连同录音填进输入条，提示 `这是识别到的内容，确认或改一下，按 Enter 发送。` → 确认后 `Enter` 才真正发送；**改过文字再发，不带那段录音**（否则语速指标和文字对不上）。
- 手动输入：点 `手动输入` → 底部就地展开，placeholder `用英文写下你的回答，Enter 发送，Shift+Enter 换行`；按钮 `发送` / `收起`，有草稿时多一个 `清空草稿`；自动聚焦；`Esc` 收起但**保留草稿**，旁注 `收起不会丢掉你写的内容。`；焦点回到 `手动输入`；全程无浏览器原生弹窗。
- 失败处理：后端拒收（空/超长/502）时，刚乐观插入的那句**撤回**，原文留在输入条、输入条不关，改一下就能重发；502 文案 `你的密钥被模型服务拒绝了，去设置里换一个再试；这句话没有计入记录。`
- 静音与权限：点了不说 → `这次没听到声音，再点一次麦克风试试，或者改用「手动输入」。`；拒绝权限 → `麦克风权限被拒绝了。请在地址栏左侧允许麦克风，或改用「手动输入」。`
- 断言：两轮后 turns 5 条（ai/user/ai/user/ai）；用户原句逐字落库；改过字的请求 `audio=null`。
- 截图位 S07 对话中；S08 手动输入条展开；S09 录音中计时；S10 识别结果进输入条的确认提示。

### 步骤 6 · 结束并出报告

- 动作：右下 `结束并出报告`（**唯一入口**）→ 确认条 `生成报告后这次对话就结束了，确定吗？` → `确认生成` → `生成中…` → 跳 `/report/{id}`。
- 零轮防护：刚开练就点 → 红字 `先至少聊一轮，说一句再生成报告。`
- 聊满 4 轮：提示条 `已经聊了几轮，可以点右下「结束并出报告」看评分了。`（只有文字，不再多一个按钮）。
- 预期文案：`复盘报告`；`综合得分` + 大数字；档位 `B1 · 雅思 5.5`；小字 `分数由 AI 估算，仅供参考。`；`四个维度`（副标题 `模型分与可测指标融合`，每维带 `雅思 x.x`）；`流利度与表达指标`；`评分依据（可复现）` **默认收起**（小字 `想核对分数怎么来的再展开，学习者只看分数和等级就行。` + `展开`/`收起`）；`逐句纠错`（`原句` 红删除线 + `改写` 绿 + 中文原因）；`再来一次` / `看历史`。
- 断言：`source=llm`、`total_score` 非空、四维齐全、bands 3.0–9.0；`sentence_fixes[].original` 逐字来自用户发言。
- 降级分支：key 改坏再练 → finish 仍 200，黄色横幅 `示例报告（本次不计分）：` + 原因；`unavailable` 时不出现 `去设置`。
- 截图位 S11 报告首屏（折叠态的评分依据）；S12 逐句纠错。

### 步骤 7 · 清练习数据（重点）

- 动作：设置页 `清除我的练习数据` → 输入 `删除` → `确认删除`。
- 预期文案：`确认删除你的全部练习记录与报告？输入「删除」两个字再点确认。`；输错 `请先输入「删除」两个字`；成功 `已删除 N 次练习、M 份报告。`
- 断言：历史空态 `还没有练习记录。` + `去练一次`；`GET /auth/me` 200（账号还在）；B 的会话仍在；该用户 sessions/turns/reports 归零。
- 实测参考：2 次练习 → `deleted_sessions=2, deleted_turns=6, deleted_reports=1`。
- 截图位 S13 删除成功绿字；S14 历史空态。

### 步骤 8 · 注销账号（重点）

- 动作：`注销我的账号` → 输入 `注销` → `确认注销`。
- 预期文案：`确认注销「walkA」？输入「注销」两个字再点确认。`；输错 `请先输入「注销」两个字`；成功回 `/login`。
- 断言：`localStorage` 的 `sp_token`/`sp_llm` 被清；旧 token 401（`detail=用户不存在`）；同名可重注册。
- 实测参考：错 confirm 400 `注销不可恢复，请输入「注销」确认`；正确 200 `deleted_account=1`。
- 截图位 S15 注销确认区。

## 2. 异常项（记录现状，不阻塞发布）

| 编号 | 场景 | 操作 | 当前行为 | 期望 |
| --- | --- | --- | --- | --- |
| A | 刷新中断 | 对话 2 轮后 F5 | 工作区已落：`/practice/:id` + `GET /api/sessions/{id}` 回填，不重播开场白，恢复中显示 `正在恢复这次对话…`；`status=finished` 且有 `report_id` 直接跳报告页；他人会话 404 给 `这次对话找不到了（可能已被删除）。回首页重新开始一次吧。`。历史已按 `report_id` / `status` 分支（未完成 → `/practice/{id}`），报告页对 404 也有 `这次练习还没有报告` 空态 | 提交后真机验：刷新回填、未完成会话点进练习、降级报告点进报告 |
| B | 双开标签 | A 已开练，另一标签改 key / 注销 | 两标签内存态独立，B 改的 key 对 A 不生效（要刷新）；A 注销后 B 下一次请求 401 被踢登录（带 `next`） | A 侧提示「密钥已更新，刷新生效」 |
| C | token 过期 | 后端 `JWT_EXPIRE_MINUTES=1` 重启，登录后等 60s+ 再操作 | 401 → 跳 `/login?expired=1&next=原地址`，登录页显示 `登录状态已过期，重新登录就能接着练（练习记录还在）。`；登录成功回原页（`next` 只接受 `/` 开头、排除 `//` 与 `/login`） | 已实现，提交后真机验回跳 |
| D | 超长输入 | 手动输入粘贴 6000 字符 | 后端 400 `单轮回答太长了（上限 2000 字符），可以分两句说`；恰好 2000 收、2001 拒；先 strip 再判长；原文留在输入条；前端无字数计数 | 输入条 `maxlength=2000` + 计数，本地就拦 |
| E | 麦克风被拒 | Chrome 站点设置把麦克风设为阻止，点麦克风 | 文案 `麦克风权限被拒绝了。请在地址栏左侧允许麦克风，或改用「手动输入」。` | 已改，真机确认一次 |

补充：Firefox 点麦克风应出 `当前浏览器不支持语音识别，请用 Chrome，或点「手动输入」。`；已结束会话再发言应出 `发送失败：会话已结束`。

## 3. 本轮实测（临时库，测完已删，`backend/speakpal.db` 未动）

| 场景 | 结果 |
| --- | --- |
| 6034 字符发言 | `400`「单轮回答太长了（上限 2000 字符），可以分两句说」，不落库 |
| 恰好 2000 / 2001 | `200` / `400`；前后各 5 空格 + 2000 字符 → `200`（先 strip 再判长） |
| `""` / 空格 / 制表 / 全角空格 | 均 `400`「这一轮没有听到内容，请再说一遍或手动输入」，`turns` 不变 |

| 会话详情 `GET /sessions/{id}` | `200`，`active` + turns 1/3/5，`finished` 带 `report_id`；他人会话 404 |
| 列表 `GET /sessions` | 未完成：`status=active, report_id=null`；降级报告：`status=finished, report_id=1, total_score=null`——两者可区分 |
| 未完成会话读报告 | `404`；前端报告页落 `这次练习还没有报告` 空态（不再红字报错） |
