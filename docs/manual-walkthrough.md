# SpeakPal 真机走查脚本（产品功能体验）

| 项 | 值 |
| --- | --- |
| 适用版本 | `b0af6de` 起；前端本轮改动（去「数据存储位置」、手动输入改页面内、UI 改版）合并后**必须重走一遍** |
| 执行人 / 频次 | 产品测试；每次可演示版本 1 次，约 25 分钟 |
| 判定口径 | 主流程 8 步**全部通过**才算「可演示」；异常 5 项只记录现状与是否阻塞，不当场修 |
| 与后端验收的分工 | 代码测试覆盖 13 条接口级验收；本脚本只走**真实浏览器 + 真实麦克风**，看文案、焦点、返回路径、数据落点 |

> 本脚本的预期文案逐字取自当前代码（`frontend/src/views/*.vue`）。ui设计师改文案或布局时，要同步改这里，否则走查会误报。

## 0. 准备

1. **不要用真实库走查**。用户已要求后端用户数据清零且不保留，走查会新建账号，所以必须指到临时库：
   `DATABASE_URL=sqlite:///<仓库外临时目录>/walk.db`（PowerShell 里设环境变量后 `start-backend.bat`，前端仍走 5173 代理 8000）。走查完删临时库，`backend/speakpal.db` 保持 0 行。
2. 浏览器：Chrome（`SpeechRecognition` 只在 Chrome/Edge 可用），两档宽度 **360×640**（手机）和 **1280×800**。
3. 麦克风真机可用；另准备「麦克风=阻止」的一次开关操作（异常 E 用）。
4. 两个账号：**A** 走主流程、**B** 验证数据隔离。用户名用 `walkA` / `walkB`。
5. 截图命名 `shots/S01-register.png` … `shots/S12-mic-denied.png`，每张必须同时出现「页面标题 + 关键文案」，不截开发者工具。
6. 记录表在 §5，边走去填，别事后补。

## 1. 主流程（8 步）

### 步骤 1 · 注册 A

- 动作：打开 `http://127.0.0.1:5173` → 点「没有账号？去注册」→ 填 `walkA` / `1234` → 注册。
- 预期文案（逐字）：
  - 标题 `SpeakPal`，副标题 `场景化 AI 英语口语陪练`；
  - 输入框 placeholder：`账号`、`密码`、注册态多一个 `昵称（可选）`；
  - 按钮 `登录` ↔ `注册`；底部 `没有账号？去注册` ↔ `已有账号？去登录`。
- 断言：先空提交一次 → 红字 `请填写账号和密码`；注册成功 → `localStorage` 出现 `sp_token`、`sp_user`。
- 首跳判定（记录，不判错）：服务端 `.env` 有兜底密钥 → 直接进首页；**没有**兜底密钥 → 进 `设置` 且顶部有引导条（见步骤 2）。
- 截图位 S01：注册态表单 + 空提交后的红字。

### 步骤 2 · 填模型密钥

- 动作：设置页填一个**可用**的 DeepSeek key（Base URL / 模型留空）→ `保存`。
- 预期文案：区块标题 `模型密钥`；说明含「密钥只存在本浏览器（localStorage）…服务端不写数据库、不写日志」；保存后绿字 `已保存到本浏览器。`；底部状态行 `当前：已配置（****后四位）· 服务端已配置兜底密钥`。
- 断言：`localStorage["sp_llm"]` 有 `api_key`；`backend/speakpal.db` 里**不应**出现该 key（任何表、任何列）。
- 若首跳是引导页：同时核对黄条文案 `配一下你自己的模型密钥，之后每次练习都用它调用评分模型。没有密钥也可以先跳过，用服务端的兜底密钥。` 与 `先跳过` 能回首页。
- 截图位 S02：设置页两块（模型密钥 / 我的数据），状态行 `****xxxx` 可见；有引导页时另截 S03。

### 步骤 3 · 测试连接

- 动作一（成功）：点 `测试连接` → 预期先出 `测试中…`，再出 `连通 · 模型 deepseek-chat · 123 ms`（模型名与耗时随实际变化，格式固定）。
- 动作二（失败）：把 key 末位改掉 → 保存 → `测试连接` → 预期 `密钥无效或被拒绝：<服务端原始错误>`。
- 断言：两次都是 `POST /api/config/llm/test`；失败时响应体 `ok=false`、`error_kind=invalid_key`；响应与页面都不回显完整 key（只看后四位）。
- 截图位 S04：失败提示（用于说明「不是白屏、有明确原因」）。

### 步骤 4 · 开练

- 前置（用户明确要求，必须拆开验）：
  - 4a 点 `删除本浏览器密钥` → 回首页点任一场景 → **必须被拦住**：红字 `还没接入模型：请到「设置」里填一个 API Key，或用服务端配置的兜底密钥。`，并跳到 `设置?onboarding=1`；
  - 4b 服务端无兜底密钥时，同一动作也只能到设置页，不能建会话；断言此时 `sessions` 表 0 行。
- 动作：重新填回 key → 首页选 `咖啡店点单`，难度 `中等` → 开练。
- 预期文案：首页 `你好，walkA`、`选一个场景，开始说英语`、`和 AI 角色多轮对话，结束后拿到评分和逐句纠错。`；三张卡 `求职面试` / `咖啡店点单` / `雅思 Part 1` 各带一行描述；练习页头部 `咖啡店点单`、开场白 `Hi there! What can I get for you today?`（AI 气泡，右侧有 🔊）。
- 断言：`POST /api/sessions` 200；`turns` 表 1 行 `role=ai`；开场白会被自动朗读。
- 已知缺陷：头部难度现在显示**英文原值** `难度 medium`（应为「中等」，见 §4 D1）。
- 截图位 S05：首页三张卡（1280 宽）；S06：练习页初始态（360 宽）。

### 步骤 5 · 说两句（语音 + 手动输入）

- 动作：点 🎤 → 按钮变 `■`、录音中 → 说 `I'd like a large iced latte, please.` → 自动结束并发送 → 等 AI 英文追问。
- 动作二：点 `手动输入`。
  - **目标行为**（`design.md:113` 已禁止浏览器弹窗）：页面内出现输入框并自动聚焦；`Enter` 发送、`Shift+Enter` 换行、`Esc` 关闭；关闭后焦点回到 `手动输入` 按钮；不出现浏览器原生弹窗。
  - **现状**：`Practice.vue:111` 仍是 `window.prompt('输入你的回答（英文）')`，此步在 `b0af6de` 上**判不通过**，等前端提交后复走。
- 断言：两轮后 `turns` 4 行（ai/user/ai/user…）；用户原句逐字落库；说 `Let me think... um, I want coffee.` 这种带填充词和省略的句子，用来验报告里的纠错与填充词统计。
- 截图位 S07：对话进行中（两条用户气泡 + AI 回复 + 底部三键）；手动输入改造后补 S08（页面内输入框焦点态）。

### 步骤 6 · 结束并出报告

- 动作：点 `结束并出报告` → 按钮变 `生成中…` → 自动跳 `/report/{id}`。
- 预期文案（真实评分为准）：标题 `复盘报告`；`综合得分` + 大数字；档位胶囊 `B1 · 雅思 5.5`（格式 `CEFR · 雅思 x.x`）；下方小字 `分数由 AI 估算，仅供参考。`；区块 `四个维度`（发音清晰度 / 流利度 / 语法词汇 / 任务完成度，每项右侧带 `雅思 x.x`）、`流利度与表达指标`、`评分依据（可复现）`（每维 `模型 x · 规则 x · 最终 x`）、`逐句纠错`（原句红色删除线 + 改写绿色 + 中文原因）、底部 AI 点评、按钮 `再来一次` / `看历史`。
- 断言：`GET /api/sessions/{id}/report` 返回 `source=llm`、`total_score` 非空、四维齐全、`bands` 全在 3.0–9.0；`sentence_fixes[].original` 必须是用户真说过的句子（逐字比对，禁止虚构）。
- 降级分支（另一轮单独验）：key 改坏后再练一轮 → finish 仍 200，报告页黄色横幅 `示例报告（本次不计分）：` + 对应原因 + `去设置`；`unavailable` 时**不应**出现 `去设置`。
- 截图位 S09：报告首屏（得分 + 档位 + 四维）；S10：逐句纠错区。

### 步骤 7 · 清练习数据（只清记录）

- 动作：设置页 `清除我的练习数据` → 输入 `删除` → `确认删除`。
- 预期文案：确认区 `确认删除你的全部练习记录与报告？输入「删除」两个字再点确认。`；输错 → 红字 `请先输入「删除」两个字`；成功 → 绿字 `已删除 N 次练习、M 份报告。`；历史页变 `还没有练习记录。`
- 断言：账号还在（`GET /api/auth/me` 200，可继续用）；B 的会话仍在；`turns`/`reports` 里 A 的行归零。
- 截图位 S11：删除成功的绿字 + 历史页空态（同屏或两张）。

### 步骤 8 · 注销账号

- 动作：设置页 `注销我的账号` → 输入 `注销` → `确认注销`。
- 预期文案：确认区 `确认注销「walkA」？输入「注销」两个字再点确认。`；输错 → `请先输入「注销」两个字`；成功 → 直接回 `/login`。
- 断言：`localStorage` 里 `sp_token`/`sp_llm` 被清；拿旧 token 再请求任意接口 → 401；同名 `walkA` 能重新注册成功。
- 截图位 S12：注销确认区。

## 2. 异常项（记录现状，不阻塞发布）

| 编号 | 场景 | 操作 | 当前实测/代码行为 | 期望（产品口径） |
| --- | --- | --- | --- | --- |
| A | 刷新中断 | 对话 2 轮后 F5 | 直接回首页，对话消失；服务端会话仍是 `active`，历史里出现一条分数为 `—` 的卡片且**点了没反应**（`History.vue:21` 只在 `total_score !== null` 时跳转） | 至少给「继续上次练习」或自动收尾出报告；`—` 卡片要有继续/删除入口 |
| B | 双开标签 | A 已开练，另一个标签改 key / 注销 | 两个标签内存态独立：B 改的 key 对 A 不生效（要刷新）；A 注销后 B 下一次请求 401 被踢到登录页 | A 侧应有「密钥已更新，刷新生效」提示；被踢时说明原因 |
| C | token 过期 | 后端 `JWT_EXPIRE_MINUTES=1` 重启，登录后等 60s+ 再点历史 | `401` → 拦截器清 token 并**硬跳** `/login`，页面上没有任何「登录已失效」提示（后端 `detail=登录已失效，请重新登录` 被吞掉） | 登录页显示一次性提示，说明是过期而非注销 |
| D | 超长输入 | 手动输入粘贴 6000 字符英文 | 接口 200 照收（实测 6034 字符、2.37s，mock），前端无上限、无计数；单条气泡撑满对话区 | 前端限 500 字符左右并计数，后端 `TurnIn.transcript` 加 `max_length` 返回 422 |
| E | 麦克风被拒 | Chrome 站点设置把麦克风设为「阻止」，点 🎤 | 提示 `语音识别出错：not-allowed`（英文错误码直接露出） | 提示 `浏览器拒绝了麦克风权限，请允许后重试，或改用「手动输入」` |

补充两条容易漏的（顺手点一下即可）：Firefox 下点 🎤 应出 `当前浏览器不支持语音识别，请用 Chrome，或点「手动输入」。`；已结束的会话再发言应出 `发送失败：会话已结束`。

## 3. 本轮已实测（临时库 8060，测完已删，未碰 `backend/speakpal.db`）

| 场景 | 结果 |
| --- | --- |
| 6034 字符一次发言 | `200`，落库；2.37s（模型不可达走 mock），无截断、无报错 |
| `transcript=""` / `"   "` | `200`，**照样落库**并返回 AI 追问，`turn_index` 递增（接口层没有非空校验） |
| 过期 token / 乱码 token | 均 `401`，`detail=登录已失效，请重新登录` |
| 开练后 0 句直接 finish | `200`，`source=mock`、`total_score=null`、`sentence_fixes=[]`，报告页只会显示 `本次没有可展示的句子。` |
| 同一会话 finish 两次 | `200`，返回同一个 `report_id`（幂等） |
| 结束后再发言 | `400`，`会话已结束` |
| 历史列表 | 未评分/降级会话照样出现，分数 `—` |
| 注销 confirm 缺失 / 填 `删除` | 均 `400`，`注销不可恢复，请输入「注销」确认` |

## 4. 待确认缺陷（给负责人的定位）

- **D1** `Practice.vue:135` 显示 `难度 {{ session.difficulty }}` → 页面出现 `难度 medium`，应显示中文标签。
- **D2** `Practice.vue:111` 仍是 `window.prompt`，违反 `design.md:113`；主流程步骤 5 因此不通过。
- **D3** 会话状态只存在 Pinia 内存（`stores/session.js`），刷新即丢；无「继续练习」接口，`active` 会话永久残留。
- **D4** `History.vue:21` 只给有分的会话绑跳转：降级报告（`total_score=null`）和未完成会话都点不开，等于**看不到自己那份示例报告**。
- **D5** `schemas.py` 的 `TurnIn.transcript` 没有 `min_length`/`max_length`，空句可入库、超长不拦。
- **D6** `api/client.js` 的 401 处理直接 `window.location.href='/login'`，吞掉后端提示。
- **D7** 设置页「清除我的练习数据」无「删除几次」二次确认数量提示（只有文案确认），删完才告诉删了多少；量少可接受，量大时建议先显示条数。
