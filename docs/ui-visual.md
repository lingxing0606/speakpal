# SpeakPal 界面视觉规范 v1

> 负责人：ui设计师。落地状态：色板 / 字号 / 组件类已在 `frontend/` 生效（`tailwind.config.js`、`src/style.css`、`src/components/BrandMark.vue`），
> 已改版页面：登录、首页、历史、报告。Practice / Settings 的换肤规范见 §8，等 Chief 这两处改完再换类，避免同文件冲突。
> 本文只管视觉与交互观感，产品口径以 `docs/design.md` 为准。

## 1 气质

三个词：**可信、鼓励、专注**。

- 主色选青玉绿（声音、安静、专业），比原来的靛蓝更像「语言」，也避开所有 AI 产品都在用的蓝紫。
- 暖珊瑚**只**出现在「说话 / 录音 / 关键数字」上，一套页面里最多两处。
- **不给分数配红绿灯**。分数用墨色 + 衬线数字呈现，等级靠文字（`B1 · 雅思 5.5`）表达；红/绿只留给「错误」和「成功」这两种真实状态。理由：评分是诊断工具，不是及格线游戏。

## 3 字体与字号

- 中文：`system-ui → 微软雅黑 → Noto Sans SC`；英文：`Inter`（本地缺失时回落系统无衬线，**不引远程字体**，离线演示不能白屏掉字）。
- 数字：`.sp-num` = Georgia / Times 衬线 + `tabular-nums` + `-0.02em` 字距。只给分数、指标用，阿拉伯数字等宽才不抖。
- 字号阶梯：`56`（综合分）→ `26`（页面 h1）→ `20`（区块 h2）→ `15`（卡片标题）→ `14`（正文）→ `12`（辅助）→ `11`（字段标签）。
- 字重：标题 600–700，正文 400，按钮/表头 500。行高：标题 1.25，正文 1.6。

## 4 间距 / 圆角 / 阴影

- 4px 栅格；版心 `max-w-3xl`（768）+ 左右 16/24px；卡片内边距 24（桌面）/ 20（窄屏）；卡片间距 16。
- 圆角：卡片 `1.25rem`（20）、控件 `0.75rem`（12）、药丸 `full`、图标底 16。
- 阴影三档，全部带一点青灰而不是纯黑：
  - `shadow-card`：默认卡片
  - `shadow-soft`：按钮、小控件
  - `shadow-lift`：hover 抬升（配 `-translate-y-0.5`，2px）

## 6 页面规范

### 6.1 登录 / 注册
- 结构：`canvas` 底 + 左上 `brand-200` 光斑、右下 `coral-300` 光斑（模糊 3xl，不抢焦点）→ 品牌标 46 + 标题 + 副标题 → 400px 卡片 → 底部一行小字（记录按账号独立保存、密钥只在浏览器）。
- 字段带 12px 标签（账号 / 密码 / 昵称），不再只有 placeholder——演示时评审更容易看懂。
- 状态下移：错误用 `sp-alert-error`，落在按钮上方；提交中按钮文案变「请稍候…」并禁用；Enter 直接提交。
- 验收点：卡片垂直居中、左右光斑不出横向滚动条、Tab 三下能走完三个字段。

### 6.2 首页（选场景）
- 头部：品牌标 + 「SpeakPal」+ 竖分割 + 「你好，昵称」；右侧三个 ghost 导航（历史记录 / 设置 / 退出）。窄屏隐藏问候语，在标题下补一行。
- 标题 26px：「选一个场景，开始说英语」；难度下拉放在标题行右侧（桌面同行，窄屏换行）。
- 场景卡：图标底 44 → 名称 600 → 描述 12px 两行 → hover 才出现的「开始练习」。卡片 `hover:-translate-y-0.5 + shadow-lift + ring-brand-200`，整卡可点。
- 加载态：三张骨架卡（`animate-pulse`），不转菊花。
- 免责小字：「每一轮都由 AI 角色追问，结束后按 CEFR / 雅思量表出分」——把评测口径前置，评审一眼看到「有标准」。

### 6.3 练习页（规范见 §8，代码由 Chief 改）
- 头部：返回 + 场景名 + 难度药丸；窄屏只留返回和场景名。
- 气泡：AI 左（白底 + `ring-line`）、用户右（`brand-600` 白字）；最大宽 80%，圆角 20（同侧上角收 8）；正文 14/1.6；AI 气泡右下角 32×32 `🔊` ghost 按钮。
- 输入区：三段式——左「手动输入」ghost、中 56px 圆形录音主按钮、右「结束并出报告」软按钮；固定在底部，上方一条分割线。
- 录音中：按钮转 `coral-500` + `.sp-mic-pulse` 呼吸圈，图标 `■`；识别中的临时文本用 `brand-50` 气泡显示在消息流末尾，带省略号。
- 手动输入：**就地展开**一行输入框 + 发送按钮，`Enter` 发送、`Esc` 收起、收起后焦点回到录音按钮；**禁止 `window.prompt` / `alert` / `confirm`**（`design.md` 已写死）。
- 发送中：在该气泡下面显示三点 typing，不遮全屏；失败在输入区上方一条 `sp-alert-error`。
- 空态：只有开场问句时，录音按钮下方补一行 12px 提示「按住说话或点麦克风」。

### 6.4 报告页（视觉重点页）
- 综合分卡：居中，`56px` 衬线数字 + 墨色，上面 12px 「综合得分」，下面 `B1 · 雅思 5.5` 药丸（`brand-50` 底），再下面 note 12px；右上角一团 `brand-100` 光晕（`blur-2xl`，不超过 60% 不透明度）。
- 四维卡：标签左、分数右（16px 衬线 + 「雅思 X.X」12px 辅助），下面 8px 进度条 `brand-500`，`width` 过渡 500ms。
- 指标卡：2–3 列小格（`canvas` 底 + `line` 描边），字段 11px、值 15px 衬线。
- 评分依据：每条一块浅底，第一行「维度 + 模型/规则/最终」，note 12px，证据行 11px `ink-mute`（长文本靠它撑住可读性）。
- 逐句纠错：`原句` 11px 标签 + 原句（有改写时 `rose-500` + `line-through`）/ `改写` 标签 + `brand-700` 改写 + 下方分割线后 12px 中文原因。
- 降级报告：琥珀 alert 置顶，底部四个分数区不渲染（`hasScore` 为假），不做「空分数占位卡」。
- 操作区：等宽两个按钮（再来一次 primary / 看历史 secondary）。

### 6.5 历史
- 头部同全局；标题行「我的练习 + N 次」。
- 列表：平卡片，左场景名 + 时间，右 22px 衬线综合分 + 「综合分」小字；未出分（`total_score` 为 null）显示 `未出分` 药丸，不可点。
- 空态：圆形图标底 + 「还没有练习记录。」+ 一句解释 + 「去练一次」主按钮（原文案保留）。

## 7 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 加载 | 骨架屏 / 按钮内文案变化，禁止整页遮罩转圈 |
| 空 | 图标 + 一句现状 + 一个下一步动作 |
| 错误 | 内联 `sp-alert-error`，就地出现在出错位置上方，不弹窗、不清空已输入内容 |
| 降级（mock） | 琥珀 `sp-alert-warn` + 「去设置」链接，只在 `not_configured` / `invalid_key` 出现 |
| 危险操作 | 二次确认走页面内对话框，按钮文案写清后果（如「注销」），confirm 只认产品规定的字面值 |

## 9 动效与可访问性

- 时长：hover/按压 150ms，布局过渡 200–500ms，呼吸 1.6s；缓动统一 `ease-out`。
- `prefers-reduced-motion: reduce` 已全局把动效压到 0.001ms（`style.css`）。
- 焦点：`:focus-visible` 统一 2px `brand-300` 环 + 2px offset；不允许 `outline: none` 后不补替代。
- 点击区 ≥ 40px（ghost 按钮靠 padding 撑到 40）；正文对比度 ≥ 4.5:1；分数不单靠颜色区分。
- emoji 图标必须配文字或 `aria-label`；纯装饰的光斑加 `pointer-events-none`。
- v1 明确不做深色模式，也不做滚动视差、粒子等炫技动效。

## 10 走查清单（产品测试 / 用户模拟体验直接用）

1. 宽度 1440 / 1280 / 768 / 390 四档无横向滚动，卡片文字不溢出。
2. 登录卡片在 390 宽下不贴边（左右各 16px），光斑不出滚动条。
3. 首页场景卡 hover 有 2px 抬升 + 阴影加深，键盘 Tab 能聚焦并 Enter 进入。
4. 报告页综合分数字用衬线且切换报告时不抖动（`tabular-nums`）。
5. 降级报告是琥珀提示，不是红色；四个分数区不出现空壳。
6. 「手动输入」在页面内展开，**不出现浏览器原生弹窗**。
7. 历史空态有「去练一次」入口，未出分记录点不动。
8. 全流程 Tab 走一遍，焦点环始终可见；系统开启「减少动态效果」后无呼吸圈动画。
