# SpeakPal 界面视觉规范 v1

> 负责人：ui设计师。落地状态：色板 / 字号 / 组件类全部在 `frontend/` 生效（`tailwind.config.js`、`src/style.css`、`src/components/BrandLogo.vue`，图形资产由 logo设计师 维护）。
> 已改版页面：登录、首页、练习、报告、历史、设置。
> 待做：`/practice/:id` + 刷新回填（依赖 `GET /api/sessions/{id}`，由 功能建议 实现）。
> 本文只管视觉与交互观感，产品口径以 `docs/design.md` 为准。

## 1 气质

三个词：**可信、鼓励、专注**。

- 主色选青玉绿（声音、安静、专业），比原来的靛蓝更像「语言」，也避开所有 AI 产品都在用的蓝紫。
- 暖珊瑚**只**出现在「说话 / 录音 / 关键数字」上，一套页面里最多两处。
- **不给分数配红绿灯**。分数用墨色 + 衬线数字呈现，等级靠文字（`B1 · 雅思 5.5`）表达；红/绿只留给「错误」和「成功」这两种真实状态。理由：评分是诊断工具，不是及格线游戏。

## 3 字体与字号

- 中文：`system-ui → 微软雅黑 → Noto Sans SC`；英文：`Inter`（本地缺失时回落系统无衬线，**不引远程字体**，离线演示不能白屏掉字）。
- 数字：`.sp-num` = Georgia / Times 衬线 + `tabular-nums` + `-0.02em` 字距。只给分数、指标用，阿拉伯数字等宽才不抖。
- 字号阶梯：`56`（综合分）→ `26`（页面 h1）→ `20`（区块 h2）→ `15`（卡片标题）→ `14`（正文）→ `12`（辅助）→ `11`（字段标签）。
- 字重：标题 600–700，正文 400，按钮/表头 500。行高：标题 1.25，正文 1.6。

## 4 间距 / 圆角 / 阴影

- 4px 栅格；版心 `max-w-3xl`（768）+ 左右 16/24px；卡片内边距 24（桌面）/ 20（窄屏）；卡片间距 16。
- 圆角：卡片 `1.25rem`（20）、控件 `0.75rem`（12）、药丸 `full`、图标底 16。
- 阴影三档，全部带一点青灰而不是纯黑：
  - `shadow-card`：默认卡片
  - `shadow-soft`：按钮、小控件
  - `shadow-lift`：hover 抬升（配 `-translate-y-0.5`，2px）

## 6 页面规范

### 6.1 登录 / 注册
- 结构：`canvas` 底 + 左上 `brand-200` 光斑、右下 `coral-300` 光斑（模糊 3xl，不抢焦点）→ 品牌标 46 + 标题 + 副标题 → 400px 卡片 → 底部一行小字（记录按账号独立保存、密钥只在浏览器）。
- 字段带 12px 标签（账号 / 密码 / 昵称），placeholder 只放具体提示（「登录用户名」「至少 4 位」），**不再重复标签文字**；placeholder 用不透明 `ink-mute`（白底 5.44:1），不用带透明度的色（0.8 透明度合成后只有 3.15:1）。
- 密码框带显示/隐藏切换（眼睛按钮，`aria-label` + `aria-pressed`）；登录态下给一行「忘记密码？可以让管理员在后台重置。」——目前没有自助找回，文案不承诺做不到的事。
- 状态下移：错误用 `sp-alert-error`，落在按钮上方；提交中按钮文案变「请稍候…」并禁用；Enter 直接提交。
- 登录过期（`?expired=1`）用**中性品牌浅底**提示，不用琥珀——那不是用户的错，琥珀留给「降级/未出分」。
- 验收点：卡片垂直居中、左右光斑不出横向滚动条、Tab 能走完账号→密码→眼睛→登录、眼睛点两次类型切回来。

### 6.2 首页（选场景）
- 头部：品牌标 + 「SpeakPal」+ 竖分割 + 「你好，昵称」；右侧三个 ghost 导航（历史记录 / 设置 / 退出）。窄屏隐藏问候语，在标题下补一行。
- 标题 26px：「选一个场景，开始说英语」；难度下拉放在标题行右侧（桌面同行，窄屏换行）。
- 场景卡：图标底 44 → 名称 600 → 描述 12px 两行 → hover 才出现的「开始练习」。卡片 `hover:-translate-y-0.5 + shadow-lift + ring-brand-200`，整卡可点。
- 加载态：三张骨架卡（`animate-pulse`），不转菊花。
- 免责小字：「每一轮都由 AI 角色追问，结束后按 CEFR / 雅思量表出分」——把评测口径前置，评审一眼看到「有标准」。

### 6.3 练习页（已落地）
- 路由：`/practice/:id`。刷新后按 `GET /api/sessions/{id}` 回填 `turns`（含每轮 `input_mode`），**不重播开场白**；`status=finished` 且有 `report_id` 直接跳报告页。
- 头部：品牌标 30（与其他页头统一）+ 场景名 + 难度药丸 + **AI 语速三档**（慢 0.85 / 正常 1.0 / 快 1.15，`speechSynthesis.rate`，只影响朗读不影响评分）。
- 气泡：AI 左（白底 + `ring-line`）、用户右（`brand-600` 白字）；用户气泡**顶部带「录音 / 打字」标记**（麦克风或键盘图标 + 文字），历史回填时按 `input_mode` 还原，不让用户以为打字也被打了发音分。
- 输入区：「手动输入」secondary + 56px 录音主按钮（下方必须有「录音中 0:03」文字计时）+「结束并出报告」`sp-btn-soft`。
- 语音识别结果先填进输入条、回车才发；改过文字就不带录音，发送时显式传 `input_mode`。
- 识别错误码翻中文；点了麦克风没出声给提示并回焦；结束只有一个入口 + 页内二次确认；`should_finish` 只给只读提示。
- 空态/回填态文案、`window.prompt/alert/confirm` 全站禁用，同前。

### 6.4 报告页（视觉重点页）
- 综合分卡：居中，`56px` 衬线数字 + 墨色，上面 12px 「综合得分」，下面 `B1 · 雅思 5.5` 药丸（`brand-50` 底），再下面 note 12px；右上角一团 `brand-100` 光晕（`blur-2xl`，不超过 60% 不透明度）。
- 四维卡：标签左、分数右（16px 衬线 + 「雅思 X.X」12px 辅助），下面 8px 进度条 `brand-500`，`width` 过渡 500ms。
- 指标卡：2–3 列小格（`canvas` 底 + `line` 描边），字段 11px、值 15px 衬线。
- 作答模式横幅按后端 `answer_mode` 三选一：纯打字「本次为打字作答，发音 / 流利度未计入综合分」；混合「发音、流利度只统计录音的句子，文字表达只统计打字的句子」；纯录音不提示。老数据没有该字段时才退回查维度键。
- 维度标题跟实际维度数走（`{{n}} 个维度`），纯打字时指标卡标题写「文字表达指标」而不是「流利度与表达指标」。
- 评分依据：**默认收起**，只有标题行 + 「展开」按钮 + 一句「想核对分数怎么来的再展开」；展开后先给一句人话（模型分 → 可测指标校准 → 「最终」才进综合分），再列每条「模型 / 规则 / 最终」、note 12px、证据行 11px `ink-mute`。默认展开会把 A2/B1 看懵成「三个分数」。
- 逐句纠错：`原句` 11px 标签 + 原句（有改写时 `rose-500` + `line-through`）/ `改写` 标签 + `brand-700` 改写 + 下方分割线后 12px 中文原因。
- 降级报告：琥珀 alert 置顶，底部四个分数区不渲染（`hasScore` 为假），不做「空分数占位卡」。
- 操作区：等宽两个按钮（再来一次 primary / 看历史 secondary）。

### 6.5 历史
- 头部同全局；标题行「我的练习 + N 次」。
- 列表：平卡片，左场景名 + 时间，右 22px 衬线综合分 + 「综合分」小字；未出分显示 `未出分` 药丸。
- **全部记录可点，按字段分支**（不用「先跳报告页、404 再退回」这种试探写法）：`report_id` 非空 → 报告页（降级报告也算，那本身就是「这次不计分」的示例报告）；`status !== 'finished'` → `/practice/{id}` 接着练；两边都没有（完成却没生成报告）才落报告页的空报告说明。
- 行尾状态：有分 → 22px 衬线综合分 + 「综合分」；`active` → 「进行中」药丸 + 「继续练习」；`finished` 无分 → 「未出分」药丸 + 「看报告」。
- 场景名旁标作答模式（`answer_mode`：录音 / 打字 / 混合）；时间旁显示该次的雅思 band。
- **成长曲线用 `comparable_band`**（只取「语言复杂度 + 语用得体性」，跨模式可比），打字和录音都画在同一条线上；实心点 = 录音/混合，空心点 = 打字。`total_score` 只在同模式内可比，不拿来跨模式连线。少于 2 次不出曲线。
- 空态：圆形图标底 + 「还没有练习记录。」+ 一句解释 + 「去练一次」主按钮（原文案保留）。

### 6.6 设置
- 四段：个人资料（昵称 / 修改密码）→ 模型密钥 → 我的数据（清记录）→ 注销账号；危险动作各段独立，文案写清「只删记录」与「连账号一起删」的区别。
- **「数据存储位置」整段已删除**（用户要求，网页用不到）：路径、迁移输入、管理密钥、`GET/PUT /api/*/storage` 调用全部移除，后端接口保留为运维用途（`design.md` §13.3）。
- 密钥说明改成「不填会怎样」：不填走服务端兜底，填了优先用你的且只在本浏览器；技术细节（localStorage / 请求头 / 优先级）不再铺满一段。
- 改密码：当前密码 + 新密码 + 再输一次，前端先校验 4–64 位和一致；成功后提示「下次登录用新密码」，并明确「其他设备不会掉线」（JWT 无版本号，旧 token 仍有效）。
- 后端 422 的校验数组不直接渲染：统一折成「输入格式不对：<msg>」一句中文。
- 改密码成功后**必须把响应里的新 `token` 存回本地**（`token_version` +1 会让其他设备立刻掉线，不存回这台设备也会被踢）；页面上**不要写「其他设备不会掉线」**这类说明小字——行为已经反过来，写了就是错的，用户也不需要知道 JWT 细节。

### 6.7 欢迎页与新手引导（只跑一次）
- 路由 `/welcome`，本地标记 `sp_welcomed`；注册后或首次登录进这里，之后再登录直接进首页，`/welcome` 也进不去（守卫拦回 `/`）。
- 版式：品牌标用 `BrandLogo :size="64" wordmark layout="stacked" subtitle="场景化 AI 英语口语陪练"`（字标与配色由组件负责，**页面不要手写 SpeakPal**），下面一句人话说明要花多久、能干什么。
- 三步卡：① 选场景（列全六个场景）② 开口说或打字（明确「打字不计发音和流利度」）③ 拿评分和纠错。每张卡 44px 线性图标 + 01/02/03 编号。
- 主动作「开始第一次练习」写清下一步；底部一句「这段引导只出现这一次」。

### 6.8 开始练习的密钥门槛
- 用户要求「点场景就要先有密钥」：本浏览器没填 key 时**不直接开练**，在场景列表上方给一张页内面板（不是弹窗）：说明密钥只存在本地 + 两个按钮「去设置填密钥」「取消」，服务端有兜底 key 时额外给「用服务端密钥继续（演示）」。
- 服务端也没有兜底 key 时，面板里明说「必须自己填」，不给后门按钮——避免点下去才在练习页吃 409。

## 7 状态与反馈

| `text-rose-500` 错误行 | `sp-alert-error` |
| 临时识别气泡 `bg-indigo-100 text-indigo-700` | `bg-brand-50 text-brand-700` |

## 9 动效与可访问性

- 时长：hover/按压 150ms，布局过渡 200–500ms，呼吸 1.6s；缓动统一 `ease-out`。
- `prefers-reduced-motion: reduce` 已全局把动效压到 0.001ms（`style.css`）。
- 焦点：`:focus-visible` 统一 2px `brand-300` 环 + 2px offset；不允许 `outline: none` 后不补替代。
- 点击区 ≥ 40px（ghost 按钮靠 padding 撑到 40）；正文对比度 ≥ 4.5:1；分数不单靠颜色区分。
- emoji 图标必须配文字或 `aria-label`；纯装饰的光斑加 `pointer-events-none`。
- v1 明确不做深色模式，也不做滚动视差、粒子等炫技动效。

## 10 走查清单（产品测试 / 用户模拟体验直接用）

1. 宽度 1440 / 1280 / 768 / 390 四档无横向滚动，卡片文字不溢出。
2. 登录卡片在 390 宽下不贴边（左右各 16px），光斑不出滚动条。
3. 首页场景卡 hover 有 2px 抬升 + 阴影加深，键盘 Tab 能聚焦并 Enter 进入。
4. 报告页综合分数字用衬线且切换报告时不抖动（`tabular-nums`）。
5. 降级报告是琥珀提示，不是红色；四个分数区不出现空壳。
6. 「手动输入」在页面内展开，**不出现浏览器原生弹窗**；识别结果先落输入条、按 Enter 才发送；发送失败原文还在框里；Esc 收起不丢草稿。
7. 历史空态有「去练一次」入口；**所有记录都能点开**，未出分的进得去、没报告的给「这次练习还没有报告」+ 重新练一次。
8. 练习中 F5：地址仍是 `/practice/:id`，对话被回填、不重新念开场白；已出分的会话刷新后跳报告页。
9. 全流程 Tab 走一遍，焦点环始终可见；系统开启「减少动态效果」后无呼吸圈动画。
