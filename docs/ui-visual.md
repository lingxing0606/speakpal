# SpeakPal 界面视觉规范 v2「安静的练习室」

> 负责人：ui设计师。落地状态：色板、栅格、组件类、页头与空状态都在 `frontend/` 生效。
> 真源：`frontend/tailwind.config.js`（token）、`frontend/src/style.css`（组件类）、`frontend/src/components/`（共享件）。**本文与代码冲突时以代码为准**，改完代码回来补这一页。
> 本文只管视觉与交互观感，产品口径以 `docs/design.md` 为准。

## 1 气质与原则

三个词：**安静、可信、愿意开口**。

- 底色从冷灰改成暖纸色（`#F6F3EE`），像练习室而不是后台系统；白色只留给卡片和对话气泡。
- 主色仍是青玉绿（声音、专业），暖珊瑚只给「说话 / 录音 / 关键数字」，一屏最多两处。
- **不给分数配红绿灯**：分数用墨色 + 衬线数字，等级靠文字（`B1 · 雅思 5.5`）表达；红/绿只留给「错误」和「成功」两种真实状态。评分是诊断工具，不是及格线游戏。
- 层级靠字号、留白和字重，不靠加边框；一个区域最多一层描边。

## 3 字体与字号

- 中文：`Inter → Noto Sans SC → system-ui → 微软雅黑`；英文 `Inter`；**不引远程字体**，离线演示不能白屏掉字。
- 数字：`.sp-num` = Georgia / Times 衬线 + `tabular-nums` + `-0.02em` 字距，只给分数、指标、统计数字；中文标题一律无衬线粗体（Windows 回落宋体太细）。
- 字号阶梯：`56`（报告综合分）→ `36/28`（页面 `.sp-title`）→ `20`（区块标题）→ `15`（卡片标题）→ `14`（正文）→ `12`（辅助）→ `11`（字段标签 / eyebrow）。
- 标题区固定三件套：`.sp-eyebrow`（11px 大写、字距 0.16em）+ `.sp-title` + `.sp-lede`（14px、行高 7）。

## 4 栅格 / 间距 / 圆角 / 阴影

- 4px 刻度；组间距 20/32。`.sp-shell` 最宽 **1152px**（`max-w-6xl`），左右 20/32px；`.sp-shell-narrow` 768px（对话、表单）。`.sp-grid` 在 `lg` 起 12 列、列间距 32px，窄屏单列。
- 常用分栏：首页 7/5（问候 + 今日卡）、场景 3 列；报告 8/4（右栏分数吸顶）；历史 5/7（左栏面板、右栏看板）；设置 3/9（左分区导航 + 右内容）。
- 卡片间距 20；卡片内边距 20（窄屏）/ 24–40（桌面，报告与练习卡用大留白）。
- 圆角：卡片 `1.5rem`（`rounded-card`）、控件 `0.75rem`（12）、药丸 `full`、图标底 16。
- 阴影三档，暖棕色而不是纯黑：
  - `shadow-card`：默认卡片
  - `shadow-soft`：按钮、小控件、导航胶囊
  - `shadow-lift`：hover 抬升
  - `shadow-dock`：底部悬浮输入区

## 6 导航与页面骨架

- 桌面：`AppHeader` 右侧导航胶囊（首页 / 学习 / 笔记 / 历史 / 设置），选中项是 `ink` 底白字，跨页时滑块从上一项滑过来（380ms）。
- 移动端：同一断点（`sm`）切到底部 `TabBar`，五个 tab，当前项品牌色 + 圆底。
- **返回键只出现在详情页**：练习 `back="/"`、报告 `back="/history"`、发音对比 `back="/"`；首页/学习/笔记/历史/设置这五个顶层页不显示返回，靠导航胶囊与底部 tab 切换（这是 rc22 的定稿）。若产品要恢复顶层返回，给 `AppHeader` 传 `back` 即可，当前不是这样。
- 每个页面自己的操作放 `AppHeader` 的默认插槽（右侧），次要信息放 `#left` 插槽。

## 7 页面规范

### 7.1 登录 / 注册
- `canvas` 底 + 左上 `brand-200`、右下 `coral-300` 光斑（模糊、不抢焦点）→ 品牌标 → 标题 → 400px 卡片 → 底部一行小字。
- 字段带 12px 标签；placeholder 只放具体提示，用不透明 `ink-mute`；密码框有显示/隐藏切换。
- 错误用 `sp-alert-error` 落在按钮上方；提交中按钮文案变「请稍候…」并禁用；Enter 提交。
- 登录过期用中性品牌浅底提示，不用琥珀。

### 7.2 首页
- `AppHeader` 无标题；问候 eyebrow（按时间「早上好 / 下午好 / 晚上好」）+ 标题 + 一句说明，难度做成可点链接直达 `设置#prefs`。
- 右栏「今天」卡：连续天数 / 待复习卡 / 笔记三个 `sp-stat` + 最近 7 天小柱条；数字用 `CountUp`。
- 场景卡：色块轮换（品牌 / 珊瑚 / 沙 / 蓝 / 琥珀 / 紫，同一套低饱和），图标底 + 名称 + 描述，`sp-hover` + `.sp-arrow`。
- 缺密钥时场景上方出现页内面板：说明密钥只在本浏览器 + 「去设置填密钥」「取消」，**没有服务端密钥入口**。
- 加载用骨架卡，不用整页转圈。

### 7.3 练习页
- 窄版页头：场景名 + 难度副标题 + `back="/"`，桌面不显示主导航。
- **目标条常驻**（`sp-goal-strip`）：吸在页头下沿 `sticky top-16 z-10`，高度固定 56（桌面）/ 48（窄屏），不随目标数变化；左「本轮目标」11px + `sp-num` 计数，中 chip 单行横滚（窄屏两侧 12px 渐隐遮罩、无滚动条），右无额外元素。滚动超过 8px 才描 `line/70` 分割线；全部达成时计数转 `brand-700`、条底 `brand-100`。无 plan 时整区不渲染。
- 目标 chip 两态：未达成白底 `ink-mute` + 10px 空心环；已达成 `brand-50` 底 `brand-700` 字 + 12px ✓（h-6 / px-2.5 / 11px / 圆角全满）。chip 不是控件，不加 tabindex；计数区 `aria-live="polite"` 读「已达成 2 / 共 4 个目标」。
- 达成动效：新达成的 chip 从刚到达的 AI 气泡顶部中点飞到目标条对应 chip（420ms，同屏最多 3 个副本、间隔 70ms），落点 chip 在副本到达前 80ms 切两态并做 180ms 落地脉冲；计数 180ms 脉冲。目标条首次出现从 0 高展开 200ms。`prefers-reduced-motion` 下不生成副本、不脉冲、直接到位。
- AI 气泡白底 `ring-line`，用户气泡 `brand-600` 白字；用户气泡顶部标「录音 / 打字」，回填时按 `input_mode` 还原。
- 输入区：「手动输入」+ 56px 录音主按钮（下方有计时）+「结束并出报告」；录音可在气泡与逐句纠错旁**本地回放，只存浏览器**。
- 手动输入打开后 **8 秒没输入**，在输入框上方给一行「不知道怎么说？试试这些用法：」+ 三条 `GET /api/scenes/{id}/frames` 药丸；点一条填进输入框、光标放末尾，一打字整块收起；每次进练习页只出现一次，位置提前占一行不跳高度。
- 识别结果先落输入条，回车才发；改过文字就不带录音；识别错误码翻成中文。
- 滚动交给整页（`main` 不再 `overflow-y-auto`，否则吸顶失效）；气泡贴底用窗口滚动。

### 7.4 报告页
- 页头「复盘报告」+ `back="/history"`。
- **三个页签**：概览 / 逐句纠错 / 指标（`TABS`，默认概览）。页签条 `sp-tab-rail` 吸在页头下沿（52 高、半透明纸底、下沿 `border-line/60`）；选中是滑动白药丸（320ms），纠错/指标带 12px `sp-num` 计数、0 不显示；`role="tablist"` + 左右方向键切换。
- 页签切换：旧页 `opacity→0` + `translateX(∓16px)` 160ms，新页从对侧 `±16px` 进来 240ms（延迟 80ms），`out-in` 顺序；切换前若已滚过页签条先无动画滚回吸顶位。减少动态只做 120ms 淡入淡出。
- 概览左 8：本轮目标达成（计数旁「规则判定」11px chip，规则兜底时才出现）→「N 句可以改」入口卡（句子数 + 已通过 x/N + 去看，0 句隐藏）→ 底部动作组（按推荐再练一次 / 再来一次 / 看历史）。右 4（`lg` 吸顶）：分数 hero → 维度卡（只留数量标题）→ 点评卡。
- 逐句纠错页：汇总条（已通过 x/N + 练 ship / sheep）→ 逐句纠错列表（原句 `rose-500` + 删除线 / 改写 `brand-700` / 中文原因 12px；每句旁可回放自己的录音、重说、加入学习清单）。0 句给 `EmptyState compact icon="done"`。
- 指标页：可测指标网格直接展开（无展开/收起）；纯打字时标题写「文字表达指标」；无数据给 `EmptyState compact icon="chart"`。
- **报告里不再有「评分依据」与任何解释句**：不展示模型分/规则分/融合明细、权重表、band 口径说明；报错与降级提示照旧。
- 作答模式三选一横幅（纯打字 / 混合 / 纯录音不提示）。
- 降级报告琥珀提示置顶，分数区不渲染空壳；`mock_reason=invalid_key` 只出现在历史报告里，文案按「当时密钥失效」解释，**不再提服务端兜底**。

### 7.5 历史
- 页头「历史记录」；标题「我的练习」+ 次数。
- 顶部 `StudyDashboard`：连续天数、12 周热力图、分维度均值（空数据给空状态，缺维度不按 0 算）。
- 列表平卡片：场景名 + 时间 + 作答模式药丸 + 该次 band；右侧综合分或「未出分 / 进行中」。
- 全部记录可点，按字段分支（有报告 → 报告；未完成 → 继续练；完成无报告 → 空报告说明）。
- 成长曲线用 `comparable_band`，打字和录音同一条线（实心=录音/混合，空心=打字），**少于 2 次不渲染曲线块**；空态用 `EmptyState`。

### 7.6 学习
- 四个 tab：`复习 / 新词 / 语法 / 口语`，查询参数 `?tab=review|new|grammar|spoken`，缺省落「复习」；旧链接的 `?tab=phrase` 兼容成 `spoken`。
- 复习：`GET /api/study/today` 合并队列，组序单词 → 拼写 → 语法 → 口语 → 句型，组内按到期时间；tab 上带到期数字；空态给「学几个新词 / 看语法卡 / 去练一次」。
- 新词：三档范围卡显示「已学 N / 精选 200」，每次取 10 / 20 / 30 / 全部；加入后就地绿框确认（「已加入 10 个，1 个之前学过」），提示在刷新之后写。
- 语法：四组各 15 张，整组加入；口语：60 张，一次加 10 张。两者加入后都进「复习」，答题用 `answer` 交服务端判档。
- 加载用 `.sp-skeleton`，空态统一 `EmptyState`。

### 7.7 设置
- 页头「设置」；桌面左栏分区导航随滚动高亮，内容 3/9。
- 标题区只有 eyebrow + 标题两件套，标题到内容 24（`mb-6`）；**页头下不再有说明句**。
- 分区：个人资料 → 练习偏好（难度 / 新词范围）→ 模型密钥 → 语音合成 → 清除练习记录 → 注销账号。
- 密钥说明只讲用户需要知道的：只存在本浏览器、不上传、不写数据库；**不再提服务端兜底**；这句留在「对话密钥」分区内部。
- 从 `?onboarding=1` 进来时自动滚到模型密钥块（两帧后滚 + 120ms 补一次），不靠 URL hash。
- 危险动作各段独立，二次确认在页面内完成，「清除练习记录」和「注销账号」标题不再共用一个前缀。
- **页面以「注销账号」卡收尾**，卡下留 24（`pb-6`）；原先页脚那句说明已删除，不留占位。

### 7.8 笔记
- 页头「笔记」，**默认插槽不放按钮**（页头回到纯标题）。
- **新建移到底部动作条**：`sticky bottom-16 sm:bottom-0 z-10` + 顶部渐隐，右侧「＋ 新建笔记」（桌面 compact，窄屏全宽 py-3）；窄屏悬在 64px TabBar 之上。列表态与空态都显示，编辑态隐藏（由编辑卡内的保存 / 取消承接）。
- 列表平卡片，空态 `EmptyState`；列表底部留白 160（`pb-40`）给动作条；删除用页内确认框，不用浏览器弹窗。
- 编辑在页面内展开（列表首位），用 FLIP 从底部按钮长到落位（320ms），卡内内容延迟 120ms 淡入，列表 140ms 上移淡出；取消反向 260ms 收回按钮；减少动态时直接淡入、无位移。

## 8 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 加载 | `.sp-skeleton` 骨架 / 按钮内文案变化，禁止整页转圈 |
| 空 | `EmptyState`：插画 + 一句现状 + 一个下一步 |
| 错误 | 内联 `sp-alert-error`，就地出现在出错位置，不弹窗、不清空已输入内容 |
| 降级（mock） | 琥珀 `sp-alert-warn` + 「去设置」链接，活值只有 `not_configured` / `unavailable`；`invalid_key` 仅历史报告 |
| 危险操作 | 页内二次确认，按钮文案写清后果；confirm 只认产品规定的字面值 |

全站禁止 `window.prompt` / `alert` / `confirm`。

## 9 动效与可访问性

- 时长：hover/按压 150ms，布局过渡 200–500ms，呼吸 1.6s，导航滑块 380ms；缓动统一 `ease-out` 或 `cubic-bezier(0.2,0.7,0.2,1)`。
- `prefers-reduced-motion: reduce` 已全局把动效压到 0.001ms；`CountUp` 直接给终值。
- 焦点：`:focus-visible` 统一 2px `brand-300` 环 + 2px offset；不允许 `outline: none` 后不补替代。
- 点击区 ≥ 40px；正文对比度 ≥ 4.5:1；分数不单靠颜色区分。
- 纯装饰光斑加 `pointer-events-none`；图标按钮必须有 `aria-label`。
- 不做深色模式，不做滚动视差、粒子等炫技动效。
