## 1. 项目详情及使用方式

**SpeakPal** 是面向大学生的 AI 英语口语陪练网站，属于章程命题范围中的「智慧教育」方向。用户和 AI 扮演的角色（面试官、咖啡店店员、雅思考官、酒店前台、值机柜台、餐厅服务员）用语音或打字进行多轮对话，结束后拿到一份可以逐项核对的诊断报告，报告里的错句自动变成复习卡。

**使用方式（评委可直接按这个顺序体验）**：

1. 打开网站，注册账号。服务端开了体验额度时**不需要任何 API Key**；也可以在「设置」里填自己的 DeepSeek 等 OpenAI 兼容密钥。
2. 首页选一个场景（或「拍一张生成练习」，上传菜单、登机牌、招聘启事截图），进入对话。顶部显示本场 3 个目标，达成后自动点亮。
3. 说 3–6 轮后点「结束并出报告」，等待时能看到「评分 → 复核 → 查资料 → 生成学习卡」的进度和教练 Agent 调用工具的过程。
4. 报告页查看综合分、IELTS / CEFR 等多种量表、逐句改写、教练建议（每条附证据）和「AI 透明度」卡片。
5. 在报告里点「跟读重说」练错句，或到「复习」页按 SM-2 间隔重复复习自动生成的卡片。
6. 「设置 → 意见反馈」可以提交问题和建议。

## 2. 项目亮点

1. **分数可解释**：模型给的分会和可测规则分（语速、停顿、填充词、词汇多样性、句长、交际任务完成度）融合，模型分比规则分高出 20 分以上时会被压回。每一分都能展开看计算过程。
2. **会自己查资料的诊断教练（Agent）**：基于 Function Calling，模型自己决定调用查词、查语法卡、查历史弱项、知识检索等工具，最多 4 步。建议里引用的证据必须来自本次工具返回的结果，编造的证据会被删除。
3. **检索增强（RAG）**：评分前用 BM25 检索 60 张语法卡、60 张口语卡和 600 个核心词，作为参考注入提示词，纠错条目可以回链到具体的语法卡。离线评测见 `evaluation/rag_report.json`。
4. **多模态**：语音输入（云端转写，失败回退浏览器识别）、语音朗读、拍照生成练习场景。
5. **MCP 集成**：提供标准 MCP 服务（8 个工具 + 2 个资源），在 Claude Desktop 等客户端里可以直接问「我今天该复习什么」。
6. **AI 安全**：开启 DeepSeek 平台内容安全检查；检测提示注入；AI 回复出戏、夹杂大量中文、超长或泄露系统提示词时自动替换；任何模型故障都降级为可用状态，并在界面上明确告知。
7. **练习和复习闭环**：错句自动建卡、SM-2 调度、跟读重说、最小对立对发音辨析、随堂笔记自动关联学过的词。

## 4. 关键技术

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Vue Router（按路由懒加载）+ Tailwind CSS；`vue-tsc` 类型检查、ESLint |
| 流式交互 | 后端 SSE 逐段推送，前端 fetch + ReadableStream 解析，按帧合并渲染，支持中途停止和重试 |
| 后端 | Python FastAPI + SQLAlchemy + SQLite |
| 大模型 | DeepSeek `deepseek-flash`（对话、评分、Function Calling、图像理解、语音转写），兼容任意 OpenAI 协议服务 |
| Agent | Planner（定目标）、Critic（复核达成度）、Coach（工具调用诊断）三段编排，全部失败可降级 |
| RAG | `bm25s` 关键词检索，中英混合分词 |
| MCP | 官方 `mcp` Python SDK |
| 语音 | Web Speech API、Web Audio API 采样停顿、DeepSeek ASR、浏览器或第三方 TTS |
| 部署 | Docker（前后端一个镜像）+ Caddy 自动 HTTPS |
| 质量 | 后端 296 条自动化测试；`evaluation/` 离线信效度统计（ICC、Kappa、Bland-Altman 等） |
